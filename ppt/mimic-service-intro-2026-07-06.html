Problem

매뉴얼 하나 만드는 데
반나절이 사라집니다.

그리고 완성된 문서는 읽는 사람을 목적지까지 데려다주지 못합니다.

만들 때
캡처 → 자르기 → 화살표
→ 붙여넣기의 무한 반복

스크린샷을 찍고, 편집 도구로 표시를 그리고, 문서에 붙이고, 설명을 씁니다. 스텝 하나마다 전부 수작업입니다.

만든 뒤
완성되는 순간 낡기 시작

화면 UI가 바뀌면 문서 전체를 다시 만들어야 합니다. 업데이트가 밀리고, 아무도 안 믿는 문서가 됩니다.

읽는 사람
“그래서…
어디를 눌러요?”

글과 캡처만으로는 지금 내 화면의 어디를 클릭해야 하는지 알기 어렵습니다. 읽어도 못 따라 합니다.

답하는 사람
같은 질문, 같은 답변

결국 담당자가 반복 문의에 화면을 공유하며 하나하나 다시 설명합니다. 문서가 있는데도요.

정부24 민원 발급, 금융·행정 서비스처럼 “화면 그대로 짚어줘야” 하는 안내가 필요한 모든 조직.

공통점
설명할 시간은 부족하고, 상대는 지금 자기 화면에서 무엇을 누를지를 알고 싶어 합니다.

Solution

화면을 녹화하기만 하세요.
매뉴얼은 AI가 완성합니다.

MIMIC은 평소처럼 일하는 화면을 그대로 기록해 인터랙티브 매뉴얼로 바꿉니다. 캡처·설명·하이라이트까지 자동으로 — 그리고 필요하면 실제 사이트 위에서 클릭 위치와 입력까지 끝까지 안내합니다.

30초 만에 매뉴얼 초안 Live Guide Beta — 실행까지 동행

How it works

녹화 → AI 분석 → 완성.
이게 전부입니다.

01
평소처럼 클릭하면, 자동 캡처

크롬 확장 MIMIC Recorder를 켜고 업무를 진행하면 클릭 위치와 화면이 스텝별로 자동 기록됩니다. 별도 조작이 없습니다.

02
AI가 화면을 읽고 설명을 씁니다

“완료”를 누르면 Claude가 캡처 화면을 분석해 작업 목적 기준의 제목·단계별 설명·하이라이트를 자동 작성합니다.

03
편집하고, 링크로 공유

스텝 카드 에디터에서 제목·설명·표시를 다듬고 링크 하나로 공유합니다. 받은 사람은 설치 없이 바로 따라 합니다.

Product

문서에서 실행까지,
세 단계로 깊어지는 안내.

하나의 녹화에서 세 가지 모드가 나옵니다. 같은 콘텐츠가 읽는 문서 → 따라 하는 연습 → 실제 실행 안내로 점점 깊어집니다.

Step 1 · 매뉴얼
읽고 검색하는 기준점

스텝 카드로 정리된 문서. 팀 워크스페이스에서 공유·검색·검토의 기준이 됩니다. 가이드북으로 여러 매뉴얼을 엮을 수도 있습니다.

Step 2 · 학습 가이드
캡처 화면 위에서 안전하게 연습

실제 화면을 그대로 옮긴 캡처 위에서 클릭할 곳을 짚어가며 따라 해봅니다. 실수해도 아무 일도 일어나지 않는 저마찰 모드입니다.

Step 3 · 라이브 가이드 Beta
실제 사이트 위에서 끝까지 실행

확장 프로그램이 원본 사이트 위에 오버레이를 띄워 다음 클릭 위치를 짚고, 필요한 텍스트는 자동으로 입력하며 최종 목적지까지 동행합니다.

읽기 → 연습 → 실행, 안내의 깊이가 올라갑니다

Live Guide Beta

클릭 위치만 알려주고
끝나지 않습니다.

실제 페이지 위에 하이라이트가 떠서 다음 클릭을 짚어주고, 입력창에는 필요한 텍스트가 자동으로 채워집니다. 사용자가 하려던 일이 실제로 끝날 때까지 단계마다 함께 갑니다.

  • 다음 클릭 위치를 실제 화면 위에 표시
  • 이메일·검색어 등 필요한 텍스트 자동 입력
  • 화면이 바뀌어도 스스로 대상을 다시 찾는 self-healing

How it’s built

가볍게 시작해서 안전하게 확장되는 구조.

Under the hood

화면이 바뀌어도 길을 잃지 않도록,
6단계 타기팅 사다리.

라이브 가이드가 “다음 클릭할 곳”을 찾을 때, 하나가 실패하면 다음 방법으로 자동 전환됩니다. 가짜 위치를 찍지 않는 것이 원칙입니다.

1작성자 보정 핫스팟 — 스튜디오에서 사람이 직접 짚은 위치가 최우선
2CSS Selector — 요소의 구조적 주소로 탐색
3XPath — 셀렉터가 깨졌을 때의 대체 경로
4Fuzzy Self-healing — 텍스트·속성 유사도로 스스로 복구
5좌표 Fallback — 녹화 당시 요소 위치·클릭 좌표 활용
6AI 비주얼 리그라운딩 — 그래도 없으면 AI가 화면을 다시 보고 찾음
그래도 못 찾으면?

가짜 위치를 찍는 대신 기다림 → 건너뛰기 → 보정 유도로 흐르고, 실패 데이터는 수집되어 다음 개선에 쓰입니다.

한 번 저장, 어디서나 동일

스튜디오에서 보정한 값이 학습 가이드·공유 뷰·라이브 가이드에 동일하게 흐르도록 payload를 맞춥니다.
