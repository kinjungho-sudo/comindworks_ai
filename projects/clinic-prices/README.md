# 시술가 시세 앱 (clinic-prices)

주변 피부과 강남언니 **이벤트가** 조사 결과를 휴대폰·다른 컴퓨터에서도 보는 앱. **로그인(비밀번호) 필요, 병원 내부 참고용.**

- 주소: https://clinic-prices.vercel.app
- 비밀번호: 맥미니 `projects/clinic-prices/.env.local`의 `APP_PASSWORD` (git에 올라가지 않음)

## 화면
- **전체 시술:** 시술별 병원 수, 최저·중앙값·최고, 샷·cc당 가격, 흔한 용량 가격, 체험가 최저. 지난 조사보다 중앙값이 오르거나 내리면 ▲▼ 표시.
- **시술 상세:** 옵션별 가격 분포(점), 용량별 가격, 조사별 추이, 지난 조사 이후 바뀐 가격, 병원별 최저가, 이벤트 원문(옵션·강남언니 링크).

## 새 조사 올리기
1. 맥미니에서 조사: 블로그·SNS 앱(localhost:3300) → 시술가 시세 → **새로 조사하기** (10~15분)
2. 끝나면 같은 화면의 **배포 앱에 올리기** (1~3분). 또는 이 폴더에서 `npm run publish`.

배포 서버는 강남언니에 접속하지 않습니다. 조사는 맥미니에서만, 사람이 누를 때만 합니다.
