# 시술가 시세 앱 (clinic-prices)

주변 피부과 강남언니 **이벤트가** 조사 결과를 휴대폰·다른 컴퓨터에서도 보는 앱. 로그인 없이 열리고 검색에는 나오지 않음. **병원 내부 참고용.**

- 주소: https://clinic-prices.vercel.app (서면: /c/seomyeon)

## 화면
- **첫 화면(시술 카드):** 시술마다 같은 기준의 **단가 중앙값**(샷당·cc당·1회·1부위), 병원별 분포 그림, 흔한 용량 환산가(예: 울쎄라 100샷), 최저·최고.
- **우리 병원:** 위쪽 칸에 우리 병원 이름을 넣으면 시술마다 "N곳 중 몇 번째로 저렴"이 나옵니다. 강남언니에 없는 병원이면 시술 화면에서 우리 단가를 직접 넣으세요(이 브라우저에만 저장).
- **시술 상세:** 비교 기준(예: 인모드 얼굴 전체 / 한 부위) 고르기 → 병원별 단가 막대그래프(우리 병원 주황) → 옵션 원문 표. **모든 가격에 강남언니 원문 링크**가 있습니다.
- 첫방문·체험가와 중앙값의 30% 미만 "미끼가 의심" 가격은 비교에서 빼고 따로 보여 줍니다.

## 새 조사 올리기
1. 맥미니에서 조사: 블로그·SNS 앱(localhost:3300) → 시술가 시세 → **새로 조사하기** (10~15분)
2. 끝나면 같은 화면의 **배포 앱에 올리기** (1~3분). 또는 이 폴더에서 `npm run publish`.

배포 서버는 강남언니에 접속하지 않습니다. 조사는 맥미니에서만, 사람이 누를 때만 합니다.
