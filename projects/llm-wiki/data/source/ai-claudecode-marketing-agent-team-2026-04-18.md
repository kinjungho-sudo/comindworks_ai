# 클로드 코드로 100% 자동화 마케팅 에이전트 팀을 만드는 방법

## 원본 설명

클로드 코드를 활용해 전문적인 AI 마케팅 에이전트 팀을 구축하고 실제 업무를 자동화하는 전 과정을 상세히 소개합니다. 커서와 클로드 코드 확장 도구를 기반으로 **브랜드 가이드라인 주입부터 제미나이 이미지 API 연동, 그리고 버퍼 API를 통한 소셜 미디어 예약 배포까지** 비즈니스에 즉시 적용 가능한 워크플로우를 다룹니다.

**특히 고품질 결과물을 얻기 위해 실행 시간보다 하네스 세팅에 95%의 시간을 투자해야 하는 이유**와 구체적인 시스템 설계 방법론을 제시.

## 핵심 요점 (영상 제공)

1. 클로드 코드 사용 시 실제 실행보다 맥락을 주입하는 **하네스 세팅에 95%의 시간**을 써야 고품질 결과가 나옴
2. 브랜드 가이드라인과 디자인 스타일을 **마크다운 파일**로 정리하여 제공할 때 AI의 이해도와 작업 일관성이 극대화
3. Claude.md 파일은 프로젝트의 **표준 업무 규약인 SOP 역할**을 수행하며 여러 에이전트 간의 협업을 정교하게 제어
4. 제미나이 이미지 API와 버퍼 API를 연동함으로써 콘텐츠 기획부터 배포까지 사람의 개입을 최소화한 자동화 가능
5. 서브 에이전트별로 리서치, 디자인, 검수 등 전문 역할을 부여하고 **병렬적으로 테스크 처리**하는 구조가 비즈니스 효율을 높임

## 세부 섹션 요약 (영상 제공)

### 초기 환경 설정 및 브랜드 맥락 주입
- 커서 개발 환경에 클로드 코드 도구 세팅
- 브랜드 컨텍스트 폴더 구성
- 기존 웹사이트 스크린샷·비즈니스 자료 분석 → 브랜드 보이스·타깃 고객 페인 포인트·디자인 스타일 가이드를 마크다운으로 자동 생성
- AI에게 명확한 작업 기준 제시

### 시스템 표준화 및 전문 스킬 확장
- Claude.md = 프로젝트 두뇌 (작업 규칙·폴더 구조 정의)
- 앤트로픽 공식 스킬 설치 (PPT·PDF 등 비즈니스 문서 출력)
- 제미나이 나노바나나 MCP 연동 → 고화질 카드뉴스·썸네일 생성

### 멀티 에이전트 협업 및 자동화 배포
- 리서치→디자인→검수 마케팅 파이프라인 설계
- 각 에이전트가 팀워크 발휘 → 뉴스레터·프리젠테이션 통합 캠페인 자료 일괄 제작
- 버퍼 API 연결 → LinkedIn·Threads 등 자동 예약 포스팅
