2. 피그마 커뮤니티의 검증된 UI 키트를 클로드 디자인에 업로드 → 일관된 퀄리티 확보

## 세부 섹션 요약 (영상 제공)

### 클로드 디자인의 등장과 디자인 생태계의 변화
- 현직 디자이너들이 의존하던 **피그마 영역 공략**, 시장 충격
- 흥미로운 사실: **클로드 디자인 제작자가 피그마 출신**
- 코딩·디자인·커뮤니케이션의 경계가 허물어지는 새 작업 방식

### 디자인 시스템: 고품질 결과물의 핵심 기초
- 고품질 일관된 디자인 = 사전 세팅된 디자인 시스템 필수
- 사용 가능한 시스템:
  - 애플 iOS
  - **구글 머티리얼 디자인 3**
  - **한국 원티드 디자인 시스템** (한국 정서 최적화)
- `.fig` 파일을 클로드 디자인에 업로드 → AI가 학습 → 전문 결과물

### PRD 기반의 실무 워크플로우와 프로토타이핑
- 단순 명령어가 아닌 **PRD(제품 요구사항 문서)** 먼저 작성
- AI에게 **문맥 제공**이 중요
- 시니어 택시 앱 사례: 구체 기획서 → 가설 설정 → 인터랙티브 프로토타입 → 팀 논의 가능 시안

### 클로드 디자인 → 클로드 코드 핸드오프
- 시안을 **압축 파일 다운로드** 또는 **클로드 코드 명령어 복사** 두 가지 방법
- 디자인 시스템 컨텍스트 유지 + 실제 개발 코드 구현·수정
