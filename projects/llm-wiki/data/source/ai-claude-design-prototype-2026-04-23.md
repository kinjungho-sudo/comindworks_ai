# Claude Design 사용법 완벽 정리 — 디자이너 없이 PM·창업자가 프로토타입 만드는 법

> 출처: GPTers 커뮤니티, editor_소연 (3일 전 게시)

## 개요

**Claude Design**은 자연어로 **프로토타입·슬라이드·랜딩페이지·목업**을 만들 수 있는 **Anthropic의 AI 디자인 도구**. **2026년 4월 18일 공식 출시**. **Claude Opus 4.7**을 엔진으로 써서 디자인 배경이 없는 **창업자·PM·마케터가 머릿속 아이디어를 바로 시각 결과물로 변환** 가능.

- 인터페이스: 왼쪽 챗 + 오른쪽 캔버스
- 예: "차분한 분위기의 명상 앱 목업 만들어줘" 한 줄 → Claude가 초안 그려줌 → 대화로 다듬음
- 접근: **Claude Pro·Max·Team·Enterprise** 구독자가 `claude.ai/design`으로 바로 접속
- Free 플랜 접근 ❌

## 업계 반응
- 출시 직후 **Figma 주가 즉시 하락** (Gizmodo 보도)
- Anthropic: **"대체재가 아니라 보완재"** 공식 포지셔닝

## 핵심 기능 5가지

### 1. 자연어 → 시각물 생성 (인풋 4종)
- 텍스트 프롬프트
- 이미지
- DOCX/PPTX/XLSX 파일
- 웹 캡처 도구 (경쟁사 랜딩 통째로 가져와 "우리 브랜드로 재해석")
- 생성 속도 빠름 → 아이디어 발산 단계 유리

### 2. 디자인 시스템 자동 적용
- 온보딩에 **GitHub 코드베이스**나 기존 디자인 파일 연결
- Claude가 **색상·폰트·컴포넌트·간격 규칙** 자동 읽음
- 이후 모든 결과물에 브랜드 가이드라인 자동 적용
- 프로젝트별 디자인 시스템 분리 가능

### 3. 인라인 코멘트 + 직접 편집
- 구글 닥스처럼 특정 요소에 코멘트
- 텍스트는 캔버스에서 클릭 → 즉시 수정
- 챗으로 매번 "이 문구 바꿔줘" 필요 없음
- Figma 코멘트 피드백 플로우 그대로

### 4. 실시간 조절 슬라이더 (가장 특이)
- 결과물에 **상황별 슬라이더** 즉석 생성
- 예: 랜딩페이지 → "히어로 섹션 여백", "CTA 버튼 크기", "전체 톤 따뜻함/차가움"
- **Galileo, Uizard와 가장 차별되는 지점**
- 프롬프트 재작성 없이 미세 조정

### 5. Claude Code 핸드오프 (킬러 기능)
- "Claude Code로 전달" 버튼 → 디자인 시스템·컴포넌트·자산·상호작용 **전부 패키징**
- Claude Code 4.14 리디자인: 통합 터미널·파일 편집·HTML/PDF 프리뷰·빠른 diff 뷰어
- 핸드오프 받자마자 실제 코드 변환 + 브라우저 확인 한 화면
- **Lovable/v0와의 차이**: 둘은 "디자인=코드"로 합친 반면, Claude는 **분리하되 맥락 이어줌**

## 실전 활용 5가지

### 활용 1: 투자자 피치덱 하루 만에 완성
- 예: "B2B SaaS 시리즈A 피치덱 10장. 순서: 문제·시장규모·제품·핵심기능3·트랙션(MoM)·BM·경쟁분석·팀·재무전망·투자요청. YC 스타일 깔끔·데이터 중심"
- 인라인 코멘트로 반복 수정
- PPTX 내보내기 → PowerPoint 마지막 손질 OR Canva 원클릭
- **⚠️ Fast Company 리뷰: "기본기 좋지만 다소 정적" — 애니메이션/트랜지션은 후처리 필요**

### 활용 2: 기존 제품 랜딩페이지
- **디자인 시스템 자동 적용이 가장 빛나는 시나리오**
- GitHub 리포 연결 → 버튼·컬러·타이포 전부 인식
- "신규 기능 X 출시 랜딩. 히어로→3개 밸류 프롭→데모 영상→가격→FAQ→CTA"
- Figma 한 땀 한 땀 컴포넌트 조립 시간 통째로 사라짐

### 활용 3: 경쟁사 벤치마킹 + 리디자인
- 웹 캡처 기능으로 경쟁사 URL 던짐
- 구조·섹션·카피 전략 파악 → "구조 유지, 우리 브랜드 컬러·톤으로 재해석"
- 저작권: 단순 카피 아닌 구조·패턴만 참고 (비교적 안전), 너무 유사하면 직접 수정

### 활용 4: 모바일 앱 프로토타입으로 유저 리서치
- "20대 여성 뷰티 커머스 앱. 화면: 온보딩·홈피드·상품상세·리뷰탭·장바구니·마이페이지. 파스텔 핑크+미니멀"
- 6개 화면 일관된 디자인 시스템으로 한 번에
- 앱 개발 전 유저 리서치 비용 ↓

### 활용 5: Claude Code 핸드오프 → 실제 제품 코드
- **가장 흥미로운 조합**
- 1인 창업자의 **MVP 완성 기간이 며칠 단위로 단축**
- PM 디자인→엔지니어 코드의 핸드오프가 **한 사람 안에서 완결**

## 경쟁 도구 비교

| 도구 | 강점 | Claude Design과의 차이 |
|---|---|---|
| **Figma** | 픽셀 단위 정교 편집, 팀 협업 | 정교함↑ / 속도·자연어↓ |
| **Canva** | 템플릿 빠른 제작, 비디자이너 친화 | 템플릿 조합 중심 / Claude는 0→1 생성 |
| **v0 (Vercel)** | 디자인=코드 통합, React 직출력 | v0는 개발자 타겟 / Claude는 비개발자까지 |
| **Lovable** | 풀스택 앱 생성 | Lovable은 백엔드 포함 / Claude는 디자인 분리 |
| **Galileo, Uizard** | AI 기반 UI 생성 | 슬라이더 조정·디자인 시스템 자동 인식이 Claude 강점 |
