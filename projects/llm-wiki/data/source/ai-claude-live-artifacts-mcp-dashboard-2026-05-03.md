# 클로드 Live Artifacts + MCP — 한국 주식 모닝 브리핑 대시보드

## 원본 설명

매번 반복되는 데이터 취합과 엑셀 표 작성... 진짜 시간 낭비라고 느껴지신 적 없나요?

**클로드(Claude)의 신기능 '라이브 아티팩트(Live Artifacts)'와 'MCP'**를 활용해 매일 알아서 갱신되는 **나만의 실시간 자동화 대시보드** 제작.

이번 영상: **카카오에서 만든 'Play MCP'**를 연동하여 **[한국 주식 모닝 브리핑 대시보드]** 직접 제작. 네이버 검색, 금융감독원 DART, 주식 정보 MCP 연결 → 실시간 데이터 + 대시보드 만들기 전 꼭 고민할 5가지 핵심 질문.

> **비개발자도 SaaS 구독 대신, 내 업무에 딱 맞는 앱을 말로 직접 만드는 시대.**

## 영상 핵심 내용
- **라이브 아티팩트(Live Artifacts)**가 기존 아티팩트·스케줄 태스크와 다른 점
- **Play MCP(카카오)** 커넥터 연결 + 필수 MCP 서버 추가 방법
- 프롬프트 단 몇 줄로 실시간 맞춤형 대시보드 생성
- 대시보드 만들기 전 반드시 답해야 할 **5가지 핵심 질문**
