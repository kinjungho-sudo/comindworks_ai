# AI 시대의 디자인 시스템과 AI 슬롭 방지 전략

## 1. 개요
AI를 활용한 제품 개발 과정에서 발생하는 **디자인 품질 저하 문제**, 일명 **'AI 슬롭(AI Slop)'**의 원인 분석 + 해결 자산으로서의 **디자인 시스템** 구체적 실행 방안.

## 2. AI 슬롭 (AI Slop)

### 정의
AI가 생성한 결과물 중 **겉보기엔 그럴싸하지만 디테일 부족·어디서 본 듯한 평범한 느낌**의 저품질 결과물.

### 원인
- AI는 학습된 데이터의 **'가장 평균적인 답'**을 내놓기 때문
- 누구나 평균적인 코드를 뽑는 시대 → 코드 작성 능력보다 **제품의 '느낌(UI/UX)'**이 결정적 차별점

## 3. 디자인 시스템의 중요성
AI가 디자인 더 많이 생성할수록 디자인 시스템 가치는 오히려 ↑

- **일관성 유지**: 매뉴얼 없는 AI는 매번 다른 색상·버튼 형태 → 통일감 손상
- **브랜드 가치**: 디테일한 시스템 없으면 좋은 서비스도 저렴해 보임
- **AI 가이드**: AI는 단기 기억 부족 → **Design.md** 가이드라인 반복 제공으로 결과물 제어

## 4. 실전 디자인 가이드 — 3가지 추천 도구

| 구분 | 추천 항목 | 특징 |
|---|---|---|
| **디자인 시스템** | **원티드 몽타주** | 한국어 환경 최적화(행간·폰트 문제 해결), 상업적 이용·수정 가능 |
| **아이콘** | **쿨리콘즈 (Coolicons)** | 스타일 통일 → 화면 정돈. 흔한 오픈소스보다 특색 있음 |
| **폰트** | **프리텐다드 (Pretendard)** | 한국어 UI 표준. 사용 즉시 화면 정돈 |

### 4.1. 디테일의 핵심: 자간·행간
고급스러운 화면은 폰트 자체보다 **자간**·**행간**에서 결정됨.

- **자간(Letter Spacing)**: 약 **-0.02em** 추천 (네이버·리디북스 등 주요 서비스 활용 수치)
- **행간(Line Height)**: **1.5 ~ 1.6** 추천. 한글은 영어보다 베이스라인 낮음 → 행간 좁으면 답답함

## 5. AI 디자인 워크플로우 (5단계)

1. **기본값 설정**: 색상(5~6개) · 폰트 사이즈(6단계) · 간격(8단계) — 메뉴판처럼 단순하게
2. **Design.md 작성**: 마크다운에 정해진 디자인 규칙 + **그 이유** 기록
3. **컴포넌트 커스텀**: 검증된 구조(원티드 몽타주 등) → 브랜드 색상만 입힘
4. **아이콘 자산화**: 자주 쓰는 아이콘 약 **30개 미리 모아 톤 유지**
5. **프롬프트 전달**: AI 작업 시마다 Design.md 함께 제공 → 일관된 결과

## 6. 결론 및 향후 전망

- **디자이너 역할 변화**: 픽셀 작업자 → **시스템 설계자·품질 판단자(Curator)**
- **기술적 해자**: 코드는 흔해졌지만 브랜드만의 고유 **디자인 시스템** = AI 시대 경쟁 우위
