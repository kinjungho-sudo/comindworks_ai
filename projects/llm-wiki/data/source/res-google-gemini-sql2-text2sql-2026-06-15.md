# 원본 수집: 구글, 자연어-SQL 변환 기술 '제미나이-SQL2' 공개..."정확도 80% 돌파"

- URL: https://www.aitimes.com/news/articleView.html?idxno=211690
- 매체: AI타임스 | 기자: 박찬 | 작성일: 2026-06-13
- 수집일: 2026-06-15
- 유형: 뉴스 기사 (Text-to-SQL 기술/벤치마크)

## 핵심
구글이 자연어를 SQL 쿼리로 변환하는 차세대 기술 '제미나이-SQL2(Gemini-SQL2)'를 공개. 제미나이 3.1 프로 기반 텍스트-투-SQL 기능으로, BIRD 벤치마크에서 80.04% 실행 정확도 기록.

## 정확도 (BIRD 벤치마크, 단일 학습 모델 부문)
- 제미나이-SQL2: **80.04%**
- 기존 제미나이-SQL: 76.13% (약 +4%p 개선)
- 인간 전문가: 92.96%

## 기술 세부
- 독립 모델 아님 → 제미나이 3.1 프로 위에 구축된 Text-to-SQL 기능
- 자연어 질문 → 실제 실행 가능한 SQL로 변환 ("성공적으로 실행"이 특징)
- "복잡한 비즈니스 맥락 + 미묘한 데이터 특성 때문에 정확한 SQL 생성은 매우 어려운 문제"

## 한계
- 80% = 5건 중 1건 오류 가능 → 실무에서는 인간 검토 필수

## 활용 사례
- 수익 관리 담당자: 복잡한 조인·윈도 함수 포함 SQL 자동 생성
- 데이터 엔지니어: 빅쿼리(BigQuery) SQL 검토·수정으로 생산성 향상
- SaaS 기업: "데이터에게 질문하기" 기능 구현
