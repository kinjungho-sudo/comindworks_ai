# 인프런 LLM Wiki 강의 — 우리가 만든 것과 비교

## 핵심 요약
**실용주의개발**(네카라쿠배 실무 개발자) 출시 2026-04-25 인프런 강의, **88,000원·14강·2시간 42분**. 우리가 지금 운영 중인 **LLM Wiki 시스템과 거의 동일한 구조**를 가르침: **Obsidian + Claude Code + CLAUDE.md + 3-Layer 아키텍처 + /ingest·/tag·/lint 스킬**. 다른 점은 **개발자 대상 + "회의록·아키텍쳐 결정·트러블슈팅" 도메인**에 집중. 우리는 이미 같은 구조를 **한국어 + AI에이전트 사업 도메인 + 일기·생각 카테고리**로 운영 중.

> **결론**: 강의를 굳이 살 필요 없음. 단, **3-Layer 아키텍처 강의 1편(17:45)과 /ingest 스킬 강의(22:59)** 만 비교 학습하면 우리 시스템 검증·개선에 큰 도움. 시장 검증으로서의 가치는 매우 큼 — **시장이 이 방향을 인정하고 돈 내고 산다는 증거**.

## 강의가 답하는 6가지 페인포인트 (강의 마케팅 카피)

이 6개를 그대로 코마인드웍스 마케팅 카피로 흡수 가능:

1. 책·강의·아티클은 계속 보는데 정작 내 것이 된 게 뭔지 모를 때
2. 공부한 내용 정리하고 싶은데 정리 시간이 부담스러울 때
3. 매일 자료는 쌓이는데 필요할 때 못 찾을 때
4. ChatGPT한테 매번 프로젝트 컨텍스트를 처음부터 설명할 때
5. "3개월 전에 우리가 왜 이 라이브러리를 택했더라?"
6. 비슷한 버그를 또 처음부터 디버깅할 때

## 강의의 ★강의가 강조한 핵심 효과 (강사 본인 경험)

- 업무 아티클·논문 자동 정리 + 기존 지식과 **융합** → 빠르고 효율적 지식 축적
- 회의내용·아키텍쳐 결정사항·팀 내 일들이 **한눈에** 정리
- 트러블슈팅 목록 자동 정리 → **동일 실수 반복 방지**
- Claude 컨텍스트 사전 인지 → **프롬프팅 간결화**
  - 예: "어제 프로젝트 회의에서 결정된 내용대로 수정해서 테스트 돌려봐"

## 인사이트 (코마인드웍스 사업 연결)

### 1. 시장 검증 신호 ★★★
- LLM Wiki 시스템에 **88,000원 지불 의사** 있는 사용자 존재 (출시 4일 15명 = 약 132만 원 매출, **출시 직후 LG에너지솔루션 임직원 단체 수강**)
- 코마인드웍스 같은 솔루션이 **돈을 받을 수 있는 카테고리**라는 명확한 증거
- → **유료 오퍼 출시 시점이 빨라져야 함**

### 2. 코마인드웍스 차별화 포인트 명확화
| 포인트 | 인프런 강의 | 코마인드웍스 |
|---|---|---|
| 타깃 | 개발자 위주 | **1인 창업가·AI 에이전트 도메인** |
| 깊이 | 강의 (2h 42m) | **상시 운영 컨설팅** + 개인 코칭 |
| 스킬 | /ingest·/tag·/lint | **+ wiki-search-collect (웹 검색 자동 수집)** + 일괄수집 + 교차참조 규칙 |
| 데이터 | 강의자 데모 데이터 | **본인 LLM Wiki 50+ 페이지 (실제 운영 사례)**
| 가격 | 88,000원 | 49,000~990,000원 (Product Ladder 가능) |

### 3. 인프런 강의를 마케팅 자산으로 활용
- 이 강의가 **주류 도구로 인지도 끌어올릴 것**
- 우리는 이를 **"심화·1인 창업가용 ver."** 로 포지셔닝하면 충돌 없음
- "인프런 강의 다 들었는데 다음은 뭐?" → 코마인드웍스 컨설팅
- 인프런 강사와 협업 가능성도 검토 (브랜드 보완재)

### 4. CLAUDE.md 작성법 강의(06:14)는 짧지만 핵심
- 6분짜리 강의가 핵심이라는 건 **CLAUDE.md가 시스템 전체의 상태를 결정**한다는 뜻
- 우리 CLAUDE.md(루트 + 3개 프로젝트)는 이미 진화 중 — 이 강의 시청해서 **누락된 패턴 흡수** 가치 있음

### 5. **3-Layer 아키텍처(17:45)** 는 비교 검증 필수
- 우리 구조: `source/` (raw) → `wiki/[카테고리]/` (정제) → `index.md` (목차)
- 강사 구조도 비슷할 것으로 예상되지만 **이름·디렉토리 구조 차이 가능**
- 차이가 있다면 **우리 시스템 개선 또는 강의 설계 차이의 근거** → 검증 가치 ★★

### 6. **/ingest 스킬 강의(22:59)** 는 가장 긴 단일 강의 — 가장 중요
- 우리의 `wiki-collector` 스킬과 동일 역할
- 22분이면 **세부 구현 노하우** 공유 → 우리 wiki-collector 개선 인사이트 가능
- 이 한 강의만 따로 사거나 본인 학습 가치 있음

## 실천 방법

### 즉시 (이번 주)
1. **강의 구매 결정**: 88,000원으로 **3-Layer + /ingest 강의 2편**만 봐도 본전. **구매 추천**
2. 시청 후 **우리 시스템과의 차이점 정리** (이 페이지 업데이트)
3. **차이점 → 우리 시스템 개선 PR** 1~2건 도출

### 1개월 내
4. 인프런 강사의 유튜브(@pragmatic-dev) 구독 + 추가 콘텐츠 학습
5. 인프런 강의 vs 코마인드웍스 차별화 표 마케팅 카피 초안 작성
6. **"개발자용 인프런 강의" → "1인 창업가용 코마인드웍스"** 콘텐츠 1편 제작

### 분기 내
7. 코마인드웍스 첫 유료 오퍼 출시 (인프런과 충돌 안 하는 포지셔닝)
8. 인프런 강사와 협업·콜라보레이션 가능성 탐색
