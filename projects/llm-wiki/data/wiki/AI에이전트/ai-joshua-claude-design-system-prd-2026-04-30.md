# 클로드 디자인 잘 쓰는 법 — 99%가 '시스템' 없이 접근

## 핵심 요약
**프로덕트 디자이너 JOSHUA**가 [[ai-claudecode-marketing-agent-team-2026-04-18]] 다음으로 공개한 **Claude Design 실전 활용법**. 메인 메시지: **"99%는 시스템 없이 클로드 디자인을 쓴다"** — 즉 **디자인 시스템 세팅과 PRD 작성**이 빠지면 결과물 품질이 평범해진다. 두 가지 사전 세팅이 클로드 디자인의 진짜 힘을 뽑아내는 **하네스 엔지니어링 디자인 버전**.

> **디자인 시스템 세팅 = AI의 디자인계 하네스 엔지니어링 (JOSHUA의 정의)**

이 영상은 [[ai-claude-design-prototype-2026-04-23]]의 **실전 적용 가이드**로 직결.

---

## 핵심 2단계 세팅

### Step 1 — 디자인 시스템 세팅
사용 가능한 `.fig` 파일을 업로드하여 AI에 학습시킴:

| 시스템 | 특징 |
|---|---|
| 애플 iOS | iOS 앱 표준 |
| **구글 머티리얼 디자인 3** | 글로벌 표준, 영상에서 실습 (08:13~) |
| **원티드 디자인 시스템** | **한국 정서 최적화** (13:35~) ★ |

피그마 커뮤니티 검증된 UI 키트 업로드 → **일관된 고품질** 자동 보장.

### Step 2 — PRD (제품 요구사항 문서) 작성
- 단순 명령어 ❌ → **PRD 먼저 작성** ✅
- AI에 **문맥 제공**이 핵심
- 가설 기반 기획 (시니어 택시 앱 사례, 17:01~)
- PRD → 가설 → **인터랙티브 프로토타입** → 팀 논의 시안

## 인사이트 (코마인드웍스 사업 연결)

### 1. JOSHUA의 두 영상 연결 = 코마인드웍스 교육 커리큘럼 청사진
| | 영상 1 (마케팅 에이전트 팀) | 영상 2 (Claude Design) |
|---|---|---|
| 적용 영역 | 마케팅·콘텐츠 | UI/UX 디자인 |
| 핵심 원리 | **하네스 95% 법칙** | **디자인 시스템 + PRD** |
| 결과물 | LinkedIn·Threads 자동 포스팅 | 인터랙티브 프로토타입 |
| 코마인드웍스 적용 | 콘텐츠 자동화 컨설팅 | **MVP 디자인-코드 통합 워크숍** |

→ **두 영상을 합치면 1인 창업가의 풀스택 자동화 가이드**

### 2. 한국 정서 최적화 = 코마인드웍스 차별화 포인트
- **원티드 디자인 시스템** 활용은 한국 사업 디자인의 표준 후보
- 코마인드웍스가 "한국 1인 창업가에게 최적화된 AI 에이전트 가이드" 포지셔닝 강화
- → 글로벌 영어권 컨텐츠와 차별화

### 3. PRD 작성법 자체가 별도 교육 상품
- "Claude Design을 잘 쓰는 99% 차이 = PRD 작성 능력"
- 코마인드웍스 워크숍 1단계: **AI를 위한 PRD 작성법** 30분 모듈
- 그 다음 단계: 디자인 시스템 선택 → Claude Design 실전 → Claude Code 연동
- 4시간짜리 1일 워크숍 가능

### 4. 카카오T 시니어 앱 사례 = 우리 idea-collector 활용 사례
- JOSHUA가 가설 → PRD → 디자인까지 풀파이프 시연
- idea-collector에서 수집된 아이디어 1개를 같은 방식으로 풀파이프 시연하면 **MVP 콘텐츠 영상 1편** 완성

### 5. "주니어 디자이너 수준 자동" → 1인 창업가의 MVP 시간 단축
- 외주 디자인 비용 = 0원
- 시간 = 며칠 → 몇 시간
- 코마인드웍스 컨설팅의 **즉시 가시화 가능한 ROI**

## 실천 방법

### 즉시 (이번 주)
1. **원티드 디자인 시스템 .fig 다운로드** 후 본인 Claude Design 업로드 실험
2. **코마인드웍스 PRD 템플릿 작성** — `projects/llm-wiki/guidelines/prd_template.md`
3. 영상 풀 시청 (약 25분) 후 본 페이지에 **카카오T 시니어 앱 PRD 구체** 추가

### 1개월 내
4. **코마인드웍스 자체 랜딩페이지 PRD 작성** → Claude Design → Claude Code 핸드오프 풀파이프 1회 실행
5. 위 과정을 **유튜브 1편으로 녹화** (Sunny Lenarduzzi 90일 로드맵 Phase 2)
6. PRD 작성법 30분 강의 모듈 초안

### 분기 내
7. **"PRD → Claude Design → Claude Code 1일 워크숍"** 첫 유료 오퍼 출시 (49,000~99,000원)
8. JOSHUA와 **콜라보레이션 가능성 탐색** (협업 또는 보완재 포지셔닝)
