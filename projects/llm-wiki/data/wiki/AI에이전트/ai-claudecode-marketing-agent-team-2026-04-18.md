# Claude Code 마케팅 에이전트 팀 — 하네스 세팅 95% 원칙

## 핵심 요약
JOSHUA(조쉬)가 공개한 **Claude Code 기반 마케팅 에이전트 팀 구축** 실전 가이드. 핵심 메시지는 **"실제 실행 시간보다 맥락을 주입하는 하네스 세팅에 95% 시간을 투자해야 고품질 결과가 나온다"**. 브랜드 가이드라인 주입 → Claude.md SOP → 앤트로픽 공식 스킬 + 나노바나나 MCP → 서브에이전트 병렬 파이프라인 → Buffer API 자동 예약 포스팅까지, **콘텐츠 기획부터 배포까지 사람 개입 최소화** 파이프라인 완성.

> **"95% = 맥락 주입 · 5% = 실행"** — 이것이 하네스 엔지니어링의 정량적 법칙

---

## 5가지 핵심 법칙

### 1. 하네스 세팅 95% 법칙
- Claude Code의 품질 ≠ 프롬프트 품질
- 품질 = **주입된 맥락(컨텍스트) 품질**
- 실제 실행 명령 1개에 도달하기까지 **브랜드 문서·스타일 가이드·폴더 구조·SOP 정의**에 95% 시간 쏟아야 함
- 이 세팅이 잘 되면 실행은 1~2분에 끝남

### 2. 브랜드 가이드라인을 마크다운으로 정리
- 기존 웹사이트 스크린샷·비즈니스 자료 → Claude로 분석
- 산출물: **브랜드 보이스 · 타깃 고객 페인포인트 · 디자인 스타일 가이드** (3종)
- 각각 별도 `.md` 파일로 저장
- AI는 매 요청마다 이 파일들을 읽어 일관성 유지

### 3. Claude.md = 프로젝트의 SOP
- Claude.md는 단순 instruction이 아니라 **조직의 표준 업무 규약(SOP)**
- 작업 규칙·폴더 구조·에이전트 간 협업 프로토콜 정의
- 여러 서브에이전트가 같은 Claude.md 하에서 일관된 방식으로 협업

### 4. 앤트로픽 공식 스킬 + MCP 연동
- **공식 스킬**: PPT·PDF 등 비즈니스 문서 생성 (정해진 서식 정확 출력)
- **나노바나나 MCP**: 제미나이 이미지 API → 고화질 카드뉴스·썸네일 생성
- **Buffer API**: LinkedIn·Threads 등 시간대별 예약 포스팅
- → 도구 3종의 역할이 명확히 분리된 레고 블록

### 5. 서브에이전트 병렬 역할 분담
- **리서치 에이전트**: 트렌드·경쟁사 분석
- **디자인 에이전트**: 썸네일·카드뉴스 생성
- **검수 에이전트**: 브랜드 일치성·오류 검사
- 개별 성능 테스트 → 통합 캠페인 가동
- 병렬 처리로 시간 단축 + 역할별 전문성 유지

## 전체 파이프라인 아키텍처

```
[브랜드 문서 3종] 
       ↓ (Claude.md = SOP)
[리서치 에이전트] → [디자인 에이전트] → [검수 에이전트]
       ↓                    ↓                  ↓
       └──── 통합 캠페인 산출물 ────┘
                    ↓
          [앤트로픽 스킬: PPT/PDF]
          [나노바나나 MCP: 이미지]
                    ↓
              [Buffer API 예약]
                    ↓
          [LinkedIn · Threads 자동 포스팅]
```

## 인사이트 (코마인드웍스 사업 연결)

1. **"하네스 세팅 95%"는 LLM Wiki 구축 철학과 정확히 일치**
   - LLM Wiki = 내 사업의 맥락(자료·생각·일기)을 미리 잘 정리해 두는 하네스
   - Wiki 없이 실행하면 5% 시간만 쓰는 셈 = 저품질 결과
   - → LLM Wiki에 꾸준히 자료 쌓는 행위가 사업 자동화의 기반 투자

2. **코마인드웍스 서비스의 "레퍼런스 구현"**
   - 조쉬의 마케팅 팀 구축 = 내가 고객사에 제공할 서비스의 프로토타입
   - 이 파이프라인을 내 자료로 재현 → 유튜브 콘텐츠 + 실제 운영 사례화 가능
   - 1~2회 실전 운영 → 교육 프로그램 교재로 전환 (ASC 같은 멤버십 모델과 동일)

3. **서브에이전트 패턴 = 1인 창업가의 팀 대체재**
   - 리서치·디자인·검수를 모두 혼자 하면 병목
   - 서브에이전트 3개 = 3명 팀 효과
   - **내 사업에서 어떤 3가지 역할을 에이전트화할지** 당장 결정 필요
   - 후보: 수집 에이전트 / 교차참조 에이전트 / 콘텐츠 생성 에이전트

4. **Buffer API → LinkedIn · Threads 자동 포스팅**은 즉시 구현 가능
   - n8n에도 Buffer 노드 존재 → Claude Code와 n8n 둘 다 가능
   - LLM Wiki에서 매주 인사이트 3개 뽑기 → Buffer로 배포
   - **"콘텐츠 소진 없는 무한 배포 파이프라인"** 완성

## 실천 방법

### 즉시 (오늘~이번 주)
1. **브랜드 문서 3종 작성**: 코마인드웍스 보이스·타깃·디자인 가이드를 `projects/llm-wiki/data/wiki/나/` 또는 별도 브랜드 폴더에 마크다운으로 정리
2. **나노바나나 MCP 설치 테스트**: `github.com/greatSumini/nanobanana-api-mcp` 로컬 설치

### 단기 (1~2주)
3. **서브에이전트 3개 정의**: 리서치·디자인·검수 역할을 `.claude/agents/` 아래 .md로 작성
4. **Claude.md SOP 업데이트**: 3개 에이전트 간 협업 프로토콜 명시

### 중기 (1개월)
5. **Buffer API 연동**: n8n 또는 Claude Code Routines(API 트리거)로 자동 예약 구축
6. **첫 통합 캠페인 가동**: LLM Wiki에서 인사이트 1개 → 리서치→디자인→검수→포스팅 풀 파이프라인 1회 실행
