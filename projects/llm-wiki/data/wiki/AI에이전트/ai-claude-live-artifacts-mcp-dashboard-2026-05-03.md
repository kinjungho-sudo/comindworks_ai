# Claude Live Artifacts + MCP — 말로 만드는 실시간 대시보드

## 핵심 요약
**Claude의 신기능 'Live Artifacts'**가 MCP와 결합되어 **매일 알아서 갱신되는 자동화 대시보드를 비개발자도 말로 만들 수 있는 시대**가 도래. 카카오의 **Play MCP**가 한국형 MCP 게이트웨이로 등장 → **네이버 검색·금융감독원 DART·미국 주식·암호화폐·유튜브** 등 데이터 소스 묶기. 대시보드 자체보다 **"5가지 핵심 질문"이 더 중요** — 안 쓰이는 대시보드를 피하기 위한 사전 검증 프레임.

> **"이제 비개발자도 SaaS 구독 대신, 내 업무에 딱 맞는 앱을 말로 직접 만드는 시대"**
> **"도구보다 중요한 것은 '목적'"**

이는 [[ai-claude-design-prototype-2026-04-23]]·[[ai-claudecode-marketing-agent-team-2026-04-18]]에 이은 **Anthropic 생태계의 "비개발자 도구화"** 흐름 3번째 핵심 출시.

## 4가지 신규 학습 포인트 (영상 본편 정리 필요)

### 1. Live Artifacts vs 기존 Artifacts·Scheduled Tasks
- 기존 Artifacts: 정적 1회 생성
- 기존 Scheduled Tasks: 시간 예약 실행 (Routines와 유사 — [[ai-claudecode-routines-2026-04-18]])
- **Live Artifacts**: 매일 알아서 데이터 갱신되는 살아있는 페이지

### 2. Play MCP (카카오)
- 카카오톡 로그인 기반 MCP 커넥터
- 한국 데이터 소스 통합 게이트웨이로 추정
- Claude 커스텀 설정에서 연동

### 3. 다양한 MCP 서버 추가
- 네이버 검색
- 금융감독원 DART
- 미국 주식

- → MCP 생태계가 도구함처럼 모듈화

## 인사이트 (코마인드웍스 사업 연결)

### 1. **"SaaS 구독 → 나만의 앱" 메타 트렌드 = 코마인드웍스 사업 모델 정당화**
- 본 영상의 메시지 = 코마인드웍스가 노리는 시장 자체
- "1인 창업가가 자기 업무 자동화 앱을 말로 만드는 시대" → **코마인드웍스 = 그 변환을 가르치는 가이드**
- [[biz-bill-gurley-ai-survival-90percent-2026-04-30]]의 "AI 활용 능력" 자질 = 본 영상의 "말로 앱 만들기"

### 2. **5가지 핵심 질문 = 컨설팅 1주차 모듈로 직접 흡수**
- 안 쓰이는 대시보드 = 안 쓰이는 자동화 = 안 쓰이는 앱
- 코마인드웍스 컨설팅의 1주차 = 이 5가지 질문 자가진단
- → [[biz-startup-government-funding-psst-2026-05-03]]의 PSST와 결합한 **검증 프레임**

### 3. **카카오 Play MCP 활용 = 한국 1인 창업가용 차별화 콘텐츠**
- 영어권 MCP 가이드는 많지만 **한국 데이터 소스 통합**은 희귀
- 코마인드웍스 콘텐츠 1편 = "Play MCP로 만드는 한국 1인 사업 대시보드" (수금 현황·리드·공급사 가격)
- 네이버 검색·DART = 한국 시장 정보의 표준 데이터 소스

### 4. **Live Artifacts = LLM Wiki 운영 자동화 가능성**
- 매일 갱신 = LLM Wiki의 "오늘 추가된 페이지 + 만료 임박" 자동 대시보드
- 우리 wiki-inspector 결과를 Live Artifact로 띄우면 매일 한눈에 확인 가능
- 별도 웹앱 만들 필요 없이 Claude 안에서 종결

### 5. **"도구보다 목적" = 우리 콘텐츠 메시지의 검증**
- LLM Wiki·Claude Code 도구 자체가 아니라 **본인 사업 목적이 먼저**
- 코마인드웍스 첫 화면 메시지: "도구가 아닌 목적부터 묻습니다"
- [[biz-evan-carmichael-business-fundamentals-2026-04-20]]의 "비즈니스 = 타인 문제 해결"과 동일 결

## 실천 방법

### 즉시 (이번 주)
1. **Play MCP 설치 + Claude 커스텀 연동** — 30분 실험
2. **본인 사업 모닝 브리핑 대시보드 1개 생성** — 예: 코마인드웍스 일일 점검 (페이지 수·교차참조·만료 임박·신규 수집)
3. **영상 풀 시청** → 5가지 핵심 질문 본 페이지에 채우기

### 1개월 내
4. **"Play MCP로 만드는 한국 1인 사업 대시보드"** 콘텐츠 1편 (블로그 또는 유튜브)
5. **5가지 핵심 질문**을 코마인드웍스 컨설팅 1주차 모듈로 통합
6. LLM Wiki 일일 점검 Live Artifact를 매일 아침 8시 자동 실행

### 분기 내
7. **"비개발자 1인 창업가용 MCP 워크숍"** 첫 유료 오퍼 출시 (Claude Design + Code + MCP 3종 세트)
8. Play MCP 활용 사례 10개 라이브러리 구축
