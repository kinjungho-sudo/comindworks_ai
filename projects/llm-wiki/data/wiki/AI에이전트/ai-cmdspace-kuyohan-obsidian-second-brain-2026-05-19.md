# 구요한 (커맨드스페이스) — 옵시디언 세컨드 브레인

## 핵심 요약
**구요한 대표(커맨드스페이스 운영)** 인터뷰. **"AI 시대 상위 1%가 선택한 세컨드 브레인 전략"** — 옵시디언으로 지식관리 한계를 넘는 방법. 더 큰 의미는 **PKM 컨퍼런스 2025** (10/23~24, 롯데호텔 김해 + 온라인): 옵시디언·노션·크래프트·n8n·에이전트·데본씽크까지 다루는 **한국 PKM 커뮤니티의 첫 대규모 컨퍼런스**. 우리 LLM Wiki와 정확히 같은 방향의 한국 커뮤니티 발견.

> **"지식이 곧 자산인 시대, 기록이 어떻게 경쟁력이 되는가"**

## ⚠️ 수집 상태
영상 자막·설명란 모두 본편 정보 빈약 (PKM 컨퍼런스 홍보 위주). 본 페이지는 **컨퍼런스 정보 + 커뮤니티 발견 + 우리 시스템 연결 인사이트** 중심.

## 인사이트 (코마인드웍스 사업 연결)

### 1. **한국 PKM 커뮤니티 = 코마인드웍스의 직접 타깃 + 협력 후보**
- 우리가 만들고 있는 LLM Wiki는 정확히 PKM의 AI-네이티브 버전
- 커맨드스페이스는 **이미 한국에 PKM 청중을 모은 첫 번째 허브**
- → 협력·공동 행사·게스트 출연 가능성

### 2. **PKM 컨퍼런스 2025 = 코마인드웍스 데뷔 무대 후보 ★**
- 3만원 오프라인 참가 → 비용 부담 거의 없음
- 옵시디언·n8n·에이전트 다루는 청중과 **정확히 일치하는 우리 타깃**
- → **연사 지원 시도** 가치 매우 큼: "Claude Code × Obsidian × Graphify로 만든 LLM Wiki 운영기"

### 3. **구요한 = 같은 길을 먼저 간 한국 1인**
- "AI 시대 상위 1%의 세컨드 브레인" 화자
- 본인 운영 사례 → 교육 사업으로 확장 = **[[biz-comindworks-philosophy-roadmap-2026-05-04]]의 3단계 로드맵을 이미 걷고 있는 사람**
- 벤치마크 + 멘토링 후보

### 4. **PKM 도구 다양화 트렌드 = 우리도 옵시디언 외 도구 흡수 필요**
- 컨퍼런스가 옵시디언만이 아닌 **노션·크래프트·DEVONthink** 까지 다룸
- 우리 시스템도 옵시디언 단일 의존을 줄이고 **포터블한 마크다운 + git 구조** 강화 가치 있음
- → [[ai-graphify-claudecode-knowledge-graph-2026-05-19]]의 Obsidian/Neo4j/MCP 다중 출력 = 같은 흐름

### 5. **"기록이 경쟁력" = 코마인드웍스 메시지의 한국화**
- 영문권의 "second brain"·"PKM"을 한국어로 친숙하게 전달하는 화자
- 우리도 같은 한국어 자연어 톤 사용 필요
- → 우리 콘텐츠에서 "LLM Wiki" 용어와 함께 **"AI 세컨드 브레인"** 병기 검토

### 6. **저비용 컨퍼런스 모델 = 코마인드웍스 첫 행사 참고**
- 3만원에 숙박·식사 — 거의 비영리 운영
- → 청중 모으기 + 커뮤니티 구축이 1차 목표인 단계의 정석
- 코마인드웍스가 2026~2027 사이 첫 행사 운영 시 모델 참고
