# 곽봉준 — 주말 이틀에 AI 1인 사업 + 해외 런칭

## 핵심 요약
비개발자 **곽봉준**이 **주말 이틀** 만에 Claude Code(바이브코딩)로 플랫폼 MVP 개발 후 **해외 시장 수요 검증까지 완료**한 전 과정 공개. 핵심 데이터: 메타 광고 하루 3만원으로 **한국 350원/클릭 vs 해외 9원/클릭 (30배 차이)**. 코딩 지식 없이 AI만으로 가능한 1인 해외 창업의 실증.

> **"코딩 한 줄도 몰랐던 비개발자가 AI 하나로 이틀 만에 해외 사업을 만들었다"**

---

## 핵심 데이터: 한국 vs 해외 광고 비용

| 항목 | 한국 | 해외 |
|---|---|---|
| 메타 광고 예산 | 하루 3만원 | 하루 3만원 |
| 클릭당 비용 | **350원** | **9원** |
| 효율 차이 | — | **39배 저렴** |

→ **같은 돈으로 해외에서 39배 더 많은 트래픽** — 해외 시장 진출 당위성의 실전 데이터

---

## 4단계 프로세스

### 1단계: 아이디어 발굴
- 기존 1인 사업 운영 경험에서 파생된 아이디어
- "또다른 사업" → 포트폴리오식 1인 창업 접근

### 2단계: 수요 검증 (사업 시작 전)
- 개발 전에 수요 확인
- 메타 광고로 랜딩 → 클릭률·반응 측정
- → **만들기 전에 팔 수 있는지 확인** (린 스타트업 정석)

### 3단계: 주말 이틀 개발 (바이브코딩)
- 도구: **Claude Code** (클로드코드)
- 코딩 지식 없이 자연어로 플랫폼 개발
- 이틀 만에 작동하는 MVP 완성

### 4단계: 해외 런칭 + 실전 검증
- 메타 광고 한국·해외 동시 집행
- 해외 9원/클릭 → 수요 검증 완료
- → 해외 시장 본격 진입

---

## 인사이트 (코마인드웍스 사업 연결)

### 1. **해외 39배 효율 = 코마인드웍스 해외 진출 근거 데이터 ★**
- 국내 교육·SaaS 시장 vs 해외 시장 경쟁 구도 비교
- [[biz-comindworks-philosophy-roadmap-2026-05-04]] 로드맵에 해외 시장 검토 단계 추가 근거
- → **첫 달부터 해외 광고 병행 검토** (비용이 39배 낮음)

### 2. **주말 이틀 MVP = 코마인드웍스 실행 속도 기준**
- 곽봉준 사례: 아이디어 → 검증 → 개발 → 런칭 전부 1주일 이내
- [[biz-opus-clip-yan-30days-pmf-2026-05-01]] Yan의 30일 PMF와 비교: 곽봉준은 이틀
- → "생각하는 시간"보다 "만들고 검증하는 시간"이 짧아야 함

### 3. **바이브코딩 + Claude Code = 비개발자 창업의 현재 상태**
- [[ai-claudecode-goal-command-tristen-2026-05-17]] /goal 자동화 + 바이브코딩 = 비개발자가 SaaS 만드는 표준 스택
- [[ai-graphify-claudecode-knowledge-graph-2026-05-19]] Graphify 토큰 절감과 결합 시 비용도 최소화
- → 코마인드웍스 첫 SaaS 개발 방식 = 동일 스택 적용 가능

### 4. **"또다른 사업" = 포트폴리오 창업 모델**
- 1인이 여러 사업을 병렬 운영 — [[biz-peter-levels-1person-28billion-2026-04-17]] 피터 레벨스 모델과 동일
- 첫 사업으로 검증된 스킬·인프라를 두 번째 사업에 재활용
- → 코마인드웍스도 LLM Wiki → 교육 → SaaS 포트폴리오 확장 전략과 일치

### 5. **수요 검증 먼저 = 코마인드웍스 기본 원칙 재확인**
- 만들기 전에 광고로 반응 테스트
- [[biz-toss-mvp-litmers-2026-04-17]] 토스 MVP 전략과 동일 원리
- → 코마인드웍스 강의·SaaS 출시 전 랜딩 페이지 + 광고 검증 단계 필수

### 6. **한국 창업가 실사례 = 코마인드웍스 콘텐츠 레퍼런스**
- 영어권 사례(피터 레벨스·Dan Martell)와 달리 **한국인 비개발자 실증**
- "나도 할 수 있다" 심리적 장벽 제거 효과
- → 코마인드웍스 유튜브 콘텐츠에서 곽봉준 사례 인용 가능
