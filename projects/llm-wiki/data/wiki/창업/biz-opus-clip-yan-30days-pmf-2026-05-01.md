# 30일 AI 창업 플레이북 — Opus Clip CEO Yan

## 핵심 요약
**Opus Clip**(영상 자동 클리핑 SaaS, 1인 사업 → 글로벌 SaaS로 성장) CEO **Yan**의 **30일 1인 AI 창업 A to Z 플레이북**. 메시지 핵심:

> **"좋은 아이디어보다 중요한 것은 진짜 문제 해결"**
> **"고객이 실제로 돈을 지불하는 기준"을 찾는 것이 창업의 본질**

3가지 실전 기준:
1. **30일 안에 PMF(Product-Market Fit) 확인**
2. **대기업에게 잠식될 아이템 회피**
3. **반드시 좁혀야 하는 초니치 시장 전략**

빠르게 검증·빠르게 전환(Pivot) = AI 시대 생존 전략.

> [[biz-toss-mvp-litmers-2026-04-17]]의 토스 MVP·[[biz-danmartell-zero-to-1m-2026-04-17]]의 0→1M 패턴과 정확히 같은 결, 더 압축된 시간 프레임

## ⚠️ 수집 상태

- 본 페이지는 **3대 기준 + 인사이트 기반 골격**

## 3대 핵심 기준 (영상 본편 정리 필요)

### 1. 30일 안에 PMF 확인
- 일반 통념: PMF는 6개월~1년 걸린다
- Yan의 주장: **30일이면 충분**
- 핵심 가설:
  - 빠른 고객 인터뷰(첫 7일)
  - 최소 기능 구축(다음 14일)
  - 실제 결제 전환 측정(마지막 9일)
- → 30일 후 결제하는 고객이 있으면 PMF, 없으면 즉시 피벗

### 2. 대기업 잠식 회피 (실패 아이템의 특징)
- "쉬운 문제"는 OpenAI·Google·Microsoft가 이미 자체 기능으로 흡수
- **잠식되는 아이템 패턴 (추정)**:
  - 범용 AI 챗봇 인터페이스
  - 단순 텍스트 요약·번역
  - 기본 이미지 생성 래퍼
- **잠식 안 되는 아이템 패턴 (추정)**:
  - 특정 워크플로우 깊숙이 들어간 도메인 솔루션
  - 사용자별 데이터 축적이 가치인 시스템
  - 인간 신뢰가 핵심인 서비스

### 3. 초니치(Hyper-niche) 시장 전략
- "스타트업은 작은 시장의 100% > 큰 시장의 1%"
- Yan 본인 사례 (Opus Clip): "긴 영상을 짧은 클립으로 자동 변환" — 콘텐츠 크리에이터 한정
- 초니치 도달 방법:
  - 1번째 단계: 1명의 이상적 고객 페르소나 정의
  - 2번째 단계: 그 1명을 깊게 만족시키는 솔루션 구축
  - 3번째 단계: 그 1명의 동료들에게 확장

## 인사이트 (코마인드웍스 사업 연결)

### 1. **"30일 PMF" = 코마인드웍스 첫 오퍼 출시 타임라인**
- 지금까지 출시 시점이 모호했지만, **"30일 안에 결제 고객 1명"** 기준 가능
- [[biz-sunny-job-youtube-90days-2026-04-18]]의 90일과 결합:
  - 90일 = 오너드 오디언스 구축
  - **90일 중 마지막 30일에 PMF 검증** = 첫 결제 고객 1명
- → 내 사업의 가장 빠른 매출 발생 시점이 **8월 말~9월 초**로 명확화

### 2. **대기업 잠식 회피 = 코마인드웍스 포지셔닝 검증**
- "AI 에이전트 일반 가이드"는 OpenAI·Anthropic이 이미 무료로 제공
- 코마인드웍스의 차별 = **"한국 1인 창업가 + 사업 컨텍스트 주입"**
- 대기업이 흉내내기 어려운 영역: **로컬 도메인 + 1:1 코칭 + 본인 LLM Wiki 사례**
- → 현재 포지셔닝 강화 정당화

### 3. **초니치 = 코마인드웍스 첫 타깃 1명 정의 시급**
- "1인 창업가"는 너무 넓음
- 초니치 후보:
  - "한국 30~40대 IT 기획자/개발자 출신, 퇴사 후 1인 창업 준비 중, AI 도구 경험 1년 미만"
  - "한국 솔로프리너, 월 매출 500만 원~1000만 원, AI 도구로 효율 2배 만들고 싶은 사람"
  - "기존 사업체 운영 중 AI 자동화로 인건비 절감 원하는 1인 사장"
- **이번 주 안에 초니치 1명 페르소나 확정 필요**

### 4. **Opus Clip = 콘텐츠 자동화의 직접 벤치마크**
- 코마인드웍스 자체 콘텐츠 제작에 Opus Clip 사용 가능
- 1시간 유튜브 영상 → 10개 짧은 클립 → LinkedIn·Threads·인스타 자동 배포
- [[ai-claudecode-marketing-agent-team-2026-04-18]]의 Buffer API와 연결하면 **풀 자동화 콘텐츠 파이프라인**

### 5. **"빠르게 전환" = 모순 페이지 운영의 본질**
- LLM Wiki의 "교차참조·모순 감지"와 결이 같음
- 30일 검증 → 데이터로 나타난 결과 → wiki/나/회고/ 에 기록 → 다음 가설로 피벗
- LLM Wiki 자체가 30일 PMF 사이클의 메모리 시스템

## 실천 방법

### 즉시 (이번 주)
1. **영상 풀 시청** (시간 미상) → 30일 단계별 행동 본 페이지에 추가
2. **초니치 페르소나 1명 정의** — `projects/llm-wiki/data/wiki/나/생각/na-생각-초니치페르소나-2026-05-01.md` 작성
3. **첫 오퍼 가설** 작성 — 그 페르소나가 결제할 단일 오퍼

### 1개월 내 (5월 31일 D-day)
4. **30일 PMF 검증 시작** — 첫 결제 고객 1명을 5월 말까지 만들기
5. 7일 단위 검증 마일스톤 설정 (인터뷰→MVP→결제)
6. 결과 기록 → wiki/나/회고/

### 분기 내
7. PMF 통과 시: 정식 첫 유료 오퍼 출시 + Yan의 30일 플레이북을 코마인드웍스 교육 콘텐츠 1편으로 제작
8. PMF 실패 시: **즉시 피벗** — 다음 30일 사이클 시작
