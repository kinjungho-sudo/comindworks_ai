# Andrew Huberman — 동기부여 없이 작동하는 자기 시스템

## 핵심 메시지

> **"동기부여를 기다리지 마라 — 동기부여가 필요 없는 시스템을 만들어라"**

Stanford 신경과학자 Andrew Huberman이 설명하는 핵심: **동기부여는 감정이 아니라 신경과학적 메커니즘**. 특정 일상 습관을 설계하면 의지력 없이도 행동이 자동으로 실행된다.

---

## 왜 동기부여가 '필요 없어지는가'

### 기존 패러다임의 문제
```
동기부여 필요 → 행동 → 결과
       ↑
  언제 올지 모름, 감정에 의존
```

### Huberman의 신경과학 패러다임
```
습관 설계 → 도파민 루프 형성 → 자동 행동
         ↑
  뇌 회로가 만들어지면 의지력 불필요
```

---

## 핵심 개념: 도파민 & 뇌가소성

| 개념 | 설명 |
|---|---|
| **도파민** | 보상 그 자체가 아닌 **행동 직전의 예상**에서 분비 |
| **뇌 가소성** | 반복된 행동은 신경 회로를 재배선 — 습관이 '디폴트'가 됨 |
| **신경 재생** | Huberman 연구 분야 — 뇌는 변할 수 있다 |

---

## 일상 습관 설계 원칙 (영상 시청 후 보완 필요)

- **특정 시간 고정**: 같은 시간 반복 → 뇌가 준비 상태 자동 진입
- **환경 설계**: 행동을 쉽게 만드는 물리적 환경 구성
- **작은 시작**: 동기부여 없이도 시작할 수 있는 최소 단위 설정
