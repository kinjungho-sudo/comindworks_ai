# 돌담한방병원 블로그 글쓰기 가이드

_v0.1 · 2026-11-26 · 근거: 한방병원·요양병원·암요양 네이버 블로그 116개 측정(병원 글 113개) · 원본 [research/blog-study-summary.md](research/blog-study-summary.md)_

> 숫자 옆 `(측정)`은 116개에서 잰 값, `(권장)`은 우리 규칙·판단으로 정한 값입니다. 상위 글의 형식만 배웠고, 문장·이미지는 가져오지 않았습니다. 순위가 형식 때문이라고 단정하지 않습니다.
> 매주 월요일 예약 작업이 새로 쌓인 자료로 이 문서를 고칩니다.

## 이번 주 바뀐 점
- 첫 판. 다음 갱신부터 여기에 3줄로 적습니다.

## 1. 주제와 트렌드

- **최근 1개월 글에서 두드러진 형식**(측정, 최신순 46개)
  - 큰 병원 이름 + 암요양: "○○대병원 진료와 암요양을 함께 고려한다면", "○○병원 치료 중 암요양을 알아볼 때"처럼 환자가 치료받는 대학병원을 기준으로 이동·일정·생활을 다루는 글이 늘었습니다.
  - **보호자 시점**: "보호자라면 먼저 확인할 것", 가족의 입원 준비를 돕는 글.
  - **확인 기준형 제목**: "~할 때 살펴볼 점", "~를 따져보는 기준", "~하는 방법".
  - **수술·암종별 회복기 생활**: 위암 수술 후 식사, 대장암 장루 주변 피부, 유방암 수술 후 팔 감각, 갑상선암 수술 후 부종처럼 좁고 구체적인 상황.
- **돌담 주제 후보**(권장, 우리 진료 프로그램과 겹치는 것)
  1. 양산부산대학교병원에서 항암·방사선 치료 중일 때, 치료 일정과 입원 요양을 함께 고민하는 보호자가 확인할 것 [원장님 확인: 실제 이동 거리·연계 방식. '연계' '협진'은 사실일 때만]
  2. 항암 중 말초신경병증(손발 저림), 일상에서 살필 것과 상담 때 말할 것
  3. 항암 중 입맛이 없을 때 식사 — 돌담 주간 식단표를 예로
  4. 고주파 온열치료는 무엇이고 무엇이 아닌가 (방사선치료·운동과 다른 별도 항목이라는 점)
  5. 유방암 수술 후 림프부종, 입원 재활에서 살피는 것
  6. 수술 후 체력이 더디게 오를 때, 숲 산책을 무리 없이 시작하는 법
  7. 암요양병원 입원을 알아보는 보호자 체크리스트(진료 연계·응급 대응·병실 동선·식사·비용)

## 2. 제목
- 형태(측정): `[지역·병원 유형] + [구체적 상황] + [질문 또는 '확인할 점']`. 예시 형태: "양산 한방병원, 항암 중 손발 저림이 시작됐을 때 먼저 살필 것"
- 지역명은 '양산', 필요하면 '부산·울산·김해'를 한 번. 병원 이름은 제목 끝이나 본문에.
- 쓰지 않음: "최고·유일·1위", "완치·회복 보장", 다른 병원보다 낫다는 비교, 후기·체험.

## 3. 분량과 구조
- **분량**: 1,600~2,800자, 중앙값 2,100자 (측정). → 우리는 **2,000~3,000자** (권장).
- **흐름**(측정 다수 + 권장):
  1. 대표 이미지(글 제목이 들어간 카드) — 53%가 이미지로 시작 (측정)
  2. 도입 2~4문장: 그 상황에 놓인 환자·보호자의 고민을 그려 줌. 환자가 자주 묻는 질문을 일반화해 따옴표로 한 줄 넣는 방식이 많음(측정). 특정 환자의 말·경험담처럼 쓰지 않음(권장).
  3. 인용구 소제목 **3~5개**(측정: 73%가 사용, 중앙값 4개). 번호형("1. ~") 또는 질문형("~할까요?").
  4. 소제목마다: 이미지 1장 → 짧은 문단 2~4개. 첫 문장에 답.
  5. 비교·항목이 있으면 표 1개 (측정 27%).
  6. 마무리: 확인할 것 정리 → "상담 때 이렇게 말씀해 주세요" 같은 부드러운 안내 → 작성·자문 의료진 표기 → 개인차·부작용 고지 → 병원 지도 (측정 52%).
- **암 관련 글의 선**(권장): 표준치료(수술·항암·방사선)를 대신한다고 읽히지 않게. "표준치료를 이어가실 수 있도록 회복기를 살핀다"는 돌담 홈페이지의 표현 방향을 따른다.

## 4. 말투
- **합니다체**가 대부분: 116개 중 98개가 합니다체 위주, 해요체 17개 (측정). → **합니다체 기본**, 보호자 대상 글만 해요체 허용 (권장).
- 한 줄 22~38자, 중앙값 28자 (측정). 문장을 짧게 끊는다.
- 질문 문장은 전체의 3% 안팎(측정) — 소제목에만 질문을 쓰고 본문은 설명.
- '저희·본원·원장·의료진'은 글당 1~5번 (측정). 과하게 반복하지 않는다.
- 이모지 22% 사용 (측정) → **쓰지 않음** (권장, 암 환자 대상 글의 차분한 톤).
- 가운데 정렬 32% (측정) → **왼쪽 정렬** (권장, 긴 설명이 많음). 짧은 강조 문장만 가운데.

## 5. 글꼴·크기·색
- 본문 글꼴: 기본서체 64개, 나눔마루부리 27개, 나눔스퀘어 12개 (측정) → **나눔마루부리**(따뜻하고 차분함) 또는 기본서체 (권장, 한 글에 한 가지).
- 글자 크기: 16이 45개, 기본(15)이 44개 (측정) → **16** (권장, 보호자·고령 독자).
- 색: 검정 본문 + 강조색 1가지. 많이 쓰인 강조는 빨강·파랑 계열 (측정) → **돌담 홈페이지 톤의 짙은 녹색 1가지**, 빨강은 쓰지 않음 (권장, 경고처럼 보임) [디자인 확인: 브랜드 색 코드].
- 굵은 글씨 글당 1~30곳, 중앙값 14 (측정) → 소제목 아래 핵심 문장 위주로 5~10곳 (권장).
- 인용구 모양: 밑줄형·기본형·세로줄형 순 (측정) → **밑줄형으로 통일** (권장).

## 6. 이미지
- 글당 7~14장, 중앙값 10장. 1,000자당 4~7장 (측정) → **8~10장** (권장).
- 모양은 가로·세로·정사각이 섞임 (측정). 모바일에서는 세로형·정사각이 크게 보임.
- 무엇을 쓸지 (권장, 우리 규칙)
  - 쓴다: 병원 실제 사진(병실·식당·재활실·온열치료실 장비 외관·숲 산책길·대운산 풍경), 주간 식단표, 글자로 정리한 정보 카드, 단순한 도식.
  - 쓰지 않는다: 환자 얼굴, 치료 전후 비교, 시술 장면, 실제 사람처럼 보이는 AI 인물, 다른 병원·학회 자료 무단 캡처.
  - 카드 글자는 본문에도 똑같이 글자로 적는다(AI 검색이 이미지 속 글자를 못 읽음).

## 7. 태그
- 0~3개, 중앙값 2개 (측정) → **5~8개** (권장): 지역+유형 1, 암종·증상 2~3, 프로그램명 1~2, 병원명 1.
