# AI 답변 출처 조사 + 병원 홈페이지 수집 가능 여부 (2026-11-17)

내부 자료. 글·이미지에는 실명 비공개 규칙이 그대로 적용된다.

## 1. AI 답변 출처 조사

- 방법: 질문 6개 × ChatGPT(gpt-4.1 웹 검색)·Gemini(2.5 flash, Google 검색)·Claude(웹 검색) × 1회. 답변 18개, 인용 84개.
- 질문: 서면 피부과 추천 / 서면 모공 치료 / 서면 기미 레이저 (선택형), 넓은 모공 원인 / 모공 레이저 부작용 / 기미와 잡티 차이 (정보형)

| 인용 출처 | 정보형 (37) | 선택형 (47) |
|---|---|---|
| 병원 자체 홈페이지 | 23 | 28 |
| 플랫폼·지도·정리 사이트 | 3 | 19 |
| 대학병원 | 5 | 0 |
| 언론 | 6 | 0 |
| 네이버 블로그 | 0 | 0 |

- 정보형: 병원 홈페이지 칼럼(체인 병원의 /guide/, /column/ 페이지 등)이 주로 인용됨.
- 선택형: 고민별 시술 페이지와 병원 정리 사이트·지도가 섞여 인용됨.
- 우리 병원 홈페이지: Gemini가 "서면 피부과 추천" 답변에 1회 인용. 정보형 질문에서는 0회.
- 한계: 질문당 1회, 작은 표본. 네이버 AI 브리핑은 측정 못 함(브라우저 안전 제한).

## 2. 병원 홈페이지 수집 가능 여부

| 항목 | 결과 |
|---|---|
| robots.txt | 전체 허용 (관리자·후기 등 일부 경로만 제외), sitemap.php 있음 (143개 주소) |
| Googlebot · bingbot · ClaudeBot · OAI-SearchBot | 접속 됨 (200) |
| **GPTBot · ChatGPT-User · PerplexityBot** | **3회 모두 서버가 연결을 끊음** (robots.txt가 아니라 보안 설정으로 보임) |
| 시술 상세 페이지 116개 | 글자는 제목과 한 줄 문구뿐, 본문은 이미지 17~18장 → AI가 내용을 못 읽음 |
| 의료진 소개 페이지 | 글자로 되어 있음 (약 2만 자) |
| 칼럼·정보 게시판 | 없음 (후기·전후사진 게시판은 있음) |

- 시험 방법: 우리 컴퓨터에서 각 봇의 User-Agent 문자열로 접속. 실제 봇은 자기 IP에서 오므로 결과가 다를 수는 있다. 홈페이지 관리 측에 보안 설정을 확인받아야 한다.
- 뜻:
  - Perplexity는 지금 홈페이지를 읽지 못한다.
  - ChatGPT는 검색 색인(OAI-SearchBot)은 되지만, 사용자가 물을 때 페이지를 직접 여는 봇(ChatGPT-User)은 막혀 있다.
  - 칼럼은 이미지가 아니라 **글자(HTML)로** 올려야 AI가 읽는다.

## 3. 홈페이지 칼럼 전에 필요한 것

1. 홈페이지 관리 측(본사 또는 제작사): 칼럼 게시판 추가, 글자형 본문 지원
2. 보안 설정에서 GPTBot·ChatGPT-User·PerplexityBot 차단 해제
3. 칼럼 주소를 sitemap에 넣기
4. 실명 정책 결정: 병원 홈페이지에 올리면 병원 이름이 당연히 드러난다
