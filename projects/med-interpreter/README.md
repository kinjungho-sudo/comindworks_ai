# MediBridge — 병원 안내데스크 양방향 통역

태블릿 한 대를 직원과 외국인 손님 사이에 두고 쓰는 실시간 통역 웹앱(PWA).
한국어 ↔ 영어·중국어·일본어·러시아어·베트남어.

## 쓰는 법
1. 태블릿 브라우저(크롬/사파리)로 배포 주소 접속 → **기기 등록 코드** 입력(한 번만)
2. 공유 메뉴 → "홈 화면에 추가" 하면 전체 화면 앱처럼 열린다
3. 손님(위 화면, 뒤집혀 있음)이나 직원(아래 화면)이 언어를 고른다
4. 손님이 기록 저장 동의 여부를 고른다 (동의 안 해도 통역은 똑같이 됨)
5. 각자 마이크 버튼을 **한 번 누르고 말한다** → 말을 멈추면 자동으로 통역
   - 길게 누르고 있으면 "누르는 동안만 녹음"
   - 말하는 동안 자막이 바로 뜨고, 상대 화면에 번역문 + 음성이 나온다
6. 직원: 자주 쓰는 문장(한 번 눌러 통역) · 글자로 입력 · 손님 언어 변경 · 음성 끄기 · 대화 종료
7. 손님: 빠른 답변(네/아니요/다시 말씀해 주세요…) · 다시 듣기
8. 아무 동작 없이 3분이 지나면 다음 손님을 위해 자동 초기화

관리자 화면 `/admin` (관리자 PIN): 병원 용어집 · 자주 쓰는 문장 · 대화 기록 · 설정

## 구조
| 단계 | 방식 | 모델 (환경변수로 교체 가능) |
|---|---|---|
| 받아쓰기 | 브라우저 → OpenAI Realtime 소켓 (1회용 키, 말하는 동안 실시간 자막) | `gpt-live-transcribe` |
| 예비 받아쓰기 | 소켓 실패 시 녹음 파일 업로드 | `gpt-4o-transcribe` |
| 번역 | 서버 스트리밍, 병원 용어집·최근 대화 문맥 포함 | `gpt-5.4-mini` |
| 음성 | 24kHz PCM 스트리밍 → 받는 즉시 재생 | `gpt-4o-mini-tts` |

- 병원 용어 "학습" = 용어집. 받아쓰기 힌트 + 번역 프롬프트에 자동 반영 (재학습 불필요)
- 용어집/문장의 빈 외국어 칸은 AI가 채움, CSV 가져오기·내보내기
- 측정값(로컬): 말을 멈춘 뒤 최종 자막 ~0.7초, 상대 화면 번역 완료 ~1.5초

## 개인정보
- 동의한 대화만 메시지 저장. 미동의 대화는 언어(통계용)만 남고 종료 시 행 삭제
- 보관 기간(기본 30일) 지나면 자동 삭제: 대화 시작 시 + 매일 Vercel Cron
- DB(Supabase `medi_*` 테이블)는 RLS 켜짐·정책 없음 → 서버 secret key 로만 접근
- OpenAI API 키는 서버에만. 브라우저는 10분짜리 1회용 받아쓰기 키만 받는다
- 기기 등록 쿠키(1년) 없으면 통역 화면·API 접근 불가, 관리자는 PIN 쿠키(12시간)

## 개발
```bash
npm install
cp .env.example .env.local   # 값 채우기
npm run dev                  # http://localhost:3210
```
DB 스키마는 Supabase 마이그레이션 `medi_interpreter_init`, `medi_settings_speak_split` 참고.
초기 용어 84개·문장 27개는 `seed/seed.json` (`seed/seed.sql`).
