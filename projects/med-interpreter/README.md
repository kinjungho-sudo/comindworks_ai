# MediBridge — 병원 안내데스크 양방향 통역

태블릿 한 대를 직원과 외국인 손님 사이에 두고 쓰는 실시간 통역 웹앱(PWA).
한국어 ↔ 손님 언어 10개 (영·중·일·러·베트남·몽골·태국·인니·아랍·우즈베크).

## 쓰는 법
**버튼 없이 말하면 바로 통역**된다. 마이크가 계속 듣다가 말이 시작되면 실시간 자막을 띄우고, 0.7초 조용하면 그 문장을 통역해 상대 화면에 글자로 보여 주고 상대 쪽 스피커로 읽어 준다. 손님 언어는 말을 들으면 자동으로 알아낸다.

처음 여는 기기는 **한 화면 모드로 바로 시작**한다. 두 기기로 나눠 쓰려면 메뉴 → 화면 모드 바꾸기:
| 모드 | 언제 | 동작 |
|---|---|---|
| 데스크 화면 | 직원 앞 기기 | 직원 말(한국어)만 맡아 통역. 손님 말은 한국어 글자 + 한국어 음성 |
| 손님 화면 | 손님 앞 두 번째 기기 | **같은 데스크 번호**끼리 자동 연결(코드 입력 없음). 손님 말(외국어)만 맡아 통역. 직원 말은 손님 언어 글자 + 음성 |
| 한 화면 | 기기 하나(모니터 복제 포함) | 마이크 하나로 한국어·외국어 모두 알아듣고, 한국어 줄과 손님 언어 줄을 같이 크게 보여줌 |

1. 기기 브라우저로 배포 주소 접속 → 데스크 번호(기본 1)와 모드 선택 → "통역 시작" (등록 코드 없음)
2. 두 기기를 쓸 때: 손님 기기에서 "손님 화면 → 데스크 1" 을 누르면 같은 번호의 데스크 화면과 자동 연결 (QR로도 가능)
3. 직원 메뉴: 자주 쓰는 문장, 글자로 입력, 손님 언어 직접 지정, 마이크/소리 끄기, 새 손님(화면 비우기)
4. 손님 화면: 첫 통역 뒤 기록 저장 동의 여부를 손님 언어로 묻는다(안 해도 통역은 같음), 다시 듣기
5. 설정한 시간(기본 3분) 동안 대화가 없으면 다음 손님을 위해 자동으로 비운다

자기 기기 스피커가 통역을 읽는 동안에는 그 기기 마이크를 잠시 멈추고(되먹임 방지), 사람이 말하는 중이면 다 말할 때까지 읽기를 기다린다.
두 기기는 Supabase Realtime 채널(DB 미저장)로 대화를 실시간 공유한다.

### 창구에서 쓰는 추가 기능
| 기능 | 설명 |
|---|---|
| 사람 통역 연결 | 직원 화면 "🧑‍💼 사람 통역" → 등록된 통역 서비스 전화/화상 연결 + 손님 화면에 "통역사 연결 중" 안내. 손님도 자기 화면에서 요청 가능(데스크에 빨간 알림) |
| 의료 내용 감지 | 수술·약·금식·검사 등 의료 단어가 나오면 "사람 통역 권장" 알림 |
| 안내 자료·금액 | 층별 안내도 같은 그림을 손님 화면에 띄움(제목은 손님 언어로 함께). 대화에 키워드가 나오면 띄울지 자동 제안. 수납 금액을 크게 표시 |
| 대화 요약 | 진료실·간호사 전달용 한국어 요약(방문 목적·증상·안내 내용·확인 필요). 기록 동의한 대화는 기록에도 저장 |
| 마이크 2개 | 한 화면 모드에서 직원·손님 마이크를 따로 지정 → 두 사람이 동시에 말해도 따로 받아씀. 메뉴 → 마이크 설정 |
| 역번역 확인 | 직원 말의 통역문을 다시 한국어로 되돌려 보여주고, 숫자·시간·층·약·횟수 같은 핵심 사실이 바뀌면 "⚠ 뜻 확인" 경고 |
| 손님 언어 10개 | 영어·중국어·일본어·러시아어·베트남어·몽골어·태국어·인도네시아어·아랍어(오른쪽→왼쪽)·우즈베크어. 말을 들으면 자동 판별 (`node --experimental-strip-types lib/langs.check.mjs` 로 판별 점검) |

관리자 화면 `/admin` (관리자 PIN): 병원 용어집 · 자주 쓰는 문장 · 대화 기록 · 설정

## 구조
| 단계 | 방식 | 모델 (환경변수로 교체 가능) |
|---|---|---|
| 받아쓰기 | 계속 듣기 + 브라우저 말소리 감지 → OpenAI Realtime 소켓 (1회용 키, 언어 자동 인식, 실시간 자막) | `gpt-live-transcribe` |
| 예비 받아쓰기 | 소켓 실패 시 녹음 파일 업로드 | `gpt-4o-transcribe` |
| 번역 | 서버 스트리밍, 병원 용어집·최근 대화 문맥 포함 | `gpt-5.4-mini` |
| 음성 | 24kHz PCM 스트리밍 → 받는 즉시 재생 | `gpt-4o-mini-tts` |

- 병원 용어 "학습" = 용어집. 받아쓰기 힌트 + 번역 프롬프트에 자동 반영 (재학습 불필요)
- 용어집/문장의 빈 외국어 칸은 AI가 채움, CSV 가져오기·내보내기
- 측정값(로컬): 말을 멈춘 뒤 최종 자막 ~0.7초, 상대 화면 번역 완료 ~1.5초

## 개인정보
- 동의한 대화만 메시지 저장. 미동의 대화는 언어(통계용)만 남고 종료 시 행 삭제
- 보관 기간(기본 30일) 지나면 자동 삭제: 대화 시작 시 + 매일 Vercel Cron
- DB(Supabase `medi_*` 테이블)는 RLS 켜짐·정책 없음 → 서버 secret key 로만 접근
- OpenAI API 키는 서버에만. 브라우저는 10분짜리 1회용 받아쓰기 키만 받는다
- 통역 화면은 주소만으로 열린다(등록 코드 없음). 돈이 드는 API(받아쓰기·번역·음성)는 이 사이트 화면에서 온 요청만 받고, 한 IP 가 분당 90회를 넘으면 잠시 막는다. 관리자는 PIN 쿠키(12시간)

## 개발
```bash
npm install
cp .env.example .env.local   # 값 채우기
npm run dev                  # http://localhost:3210
```
DB 스키마는 Supabase 마이그레이션 `medi_interpreter_init`, `medi_settings_speak_split` 참고.
초기 용어 84개·문장 27개는 `seed/seed.json` (`seed/seed.sql`).
