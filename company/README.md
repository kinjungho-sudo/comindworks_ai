# CoMind Works Company

CoMind Works의 회사 운영 기록을 모으고 정리하는 기본 폴더입니다.

이 폴더의 목적은 업무 중 생기는 기록, 회의, 결정, 산출물, 개선 후보, 승인 이력, 자동화 상태, 원본 자료를 한곳에서 찾을 수 있게 만드는 것입니다.

## 폴더 구조

```text
01_daily
- 매일 회사 업무 요약

02_meetings
- 회의록, 녹음 요약, 회의 결정사항

03_decisions
- 중요한 결정 기록

04_files
- 산출물 인덱스
- 문서, PPT, Sheet, PDF, Drive 링크

05_improvements
- SOP 후보
- 에이전트 개선 후보
- 자동화 개선 아이디어

06_approvals
- 승인, 보류, 반려 기록

07_automations
- 자동화 목록과 실행 상태

08_sources
- 원본 자료 연결
- Slack, Telegram, Email, Calendar, Drive, 녹음 등

09_DR
- 설계 리뷰 / Design Review 기록
- CoMind Works OS, 에이전트 운영, 자동화, 검색/저장 규칙처럼 시스템 구조를 논의한 세션 정리
```

## 운영 원칙

```text
원본은 보존한다.
정리본은 매일 개선한다.
중요한 변경은 승인 후 공식 기록에 반영한다.
AI 에이전트는 이 폴더를 회사 운영 맥락의 기본 진입점으로 사용한다.
```
