# Company Index

> CoMind Works 회사 운영 기록의 입구입니다.

## 바로가기

```text
01_daily        매일 회사 업무 요약
02_meetings     회의록과 회의 결정사항
03_decisions    중요한 의사결정 기록
04_files        산출물과 외부 파일 인덱스
05_improvements SOP/에이전트/자동화 개선 후보
06_approvals    승인, 보류, 반려 이력
07_automations  자동화 목록과 실행 상태
08_sources      원본 자료 연결
09_DR           설계 리뷰 / Design Review 기록
```

## 현재 설계 상태

```text
Phase 1:
- [x] 기본 폴더 구조 생성
- [ ] Daily 템플릿 설계
- [ ] Meeting 템플릿 설계
- [ ] File index 템플릿 설계
- [ ] Improvement 템플릿 설계
- [ ] 매일 전체 업무 요약 cron 설계
- Slack 브리핑 채널: #일일보고
- Slack 운영 방식: Hermes 최종 취합본을 메인 메시지로 올리고, 에이전트별 상세 내용은 해당 메시지의 스레드에 정리
- Telegram 전달 방식: 전체 보고가 아니라 핵심 2~3줄 요약 알림만 전송
```

## 사용 규칙

```text
1. 새 기록은 가장 알맞은 폴더에 Markdown으로 저장한다.
2. Google Drive, GitHub, Slack, Telegram 등 외부 자료는 링크와 메타데이터를 남긴다.
3. 원본 자료는 08_sources에 연결하거나 위치를 기록한다.
4. 공식 SOP나 운영 규칙 반영은 승인 후 진행한다.
5. 매일 요약은 01_daily에 저장한다.
```
