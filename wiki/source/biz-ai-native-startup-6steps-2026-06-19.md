# AI-네이티브 스타트업을 만드는 방법

## 핵심 개념

"AI가 반복 업무를 야간에 처리하는 동안 창업자는 제품 개선에 집중"하는 새로운 운영 모델.
진정한 경쟁 우위는 "회사가 학습·반복·진화하는 속도"에 있다.

## 6단계 프로세스

1. **업무 매핑**: 반복되는 작업을 자율성 레벨(L1~L4)로 분류
2. **컨텍스트 시스템**: Git 저장소 기반의 회사 운영 기억 구축
3. **단순한 자동화 선택**: 스크립트, AI 보조, 워크플로, 에이전트 중 최적 도구 선택
4. **스킬과 평가 지표(eval) 인코딩**: 반복 작업의 재사용 가능한 지침 개발
5. **팀의 AI-네이티브 전환**: 모든 구성원이 에이전트 활용 방식 학습
6. **피드백 루프 운영**: 매주 시스템 개선과 시장 학습

## 성공의 핵심

"모두가 같은 모델을 쓰는 환경에서 진짜 해자는 규율" — 매주 업무를 매핑하고 컨텍스트를 쌓고 eval을 쓰고 루프를 돌리는 일관성.
