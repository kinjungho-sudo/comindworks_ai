# 병원 블로그 품질 기준 v1.0

_벤치마크(국내 병원·기관 글 23건 + 해외 기관 6곳)와 GEO 근거를 바탕으로 작성. 피부과 글로 검증했고 다른 진료과에도 같은 틀을 쓴다._

## 0. 우선순위 (충돌하면 위가 이긴다)

1. **의료광고 규정** — 의료법 제56조 제2항·시행령 제23조. GEO 점수를 위해 규정을 굽히지 않는다.
2. **사실 정확성** — 모든 의학 주장은 인용 문헌이 실제로 받쳐야 한다(원문 대조).
3. **GEO** — AI 검색이 인용하기 좋은 구조·근거·신뢰 신호.
4. **가독성** — 의학 지식 없는 예비 고객이 휴대폰으로 끝까지 읽을 수 있게.

## 2. 글 구조 (본문 공백 제외 2,500~4,000자 — 글자 수는 `scripts/geo_check.py` G23으로 센다. `wc -m`은 C 로케일에서 바이트를 세므로 쓰지 않는다)

1. **제목** — 증상·시술 키워드 + 질문형 또는 "○○ 알아둘 점". 병원명·최상급 금지. 15~45자.
2. **작성 정보 박스** — 작성, 의학 감수(자격), 작성일, 최종 검토일, 다음 검토 예정일, "정보 제공 목적·AI 보조 작성" 고지.
3. **도입** — 첫 문장은 정의문("○○는 …예요"). 독자의 흔한 고민 한 문장. 환자 사례 금지.
4. **핵심 정리 박스** — 3~4줄, 혼자 읽어도 이해되게.
5. **이미지 1** — 원리·유형 도식(AI 일러스트 + 직접 얹은 라벨).
6. **질문형 섹션 5~7개** — 각 섹션 첫 문장이 직답. 필수 포함:
   - 무엇인가·헷갈리는 것과의 구분
   - 원인·악화 요인
   - 진단·확인 방법(진료가 필요한 이유)
   - 치료 선택지(표: 대상·원리·한계). 우열 결론 금지
   - **부작용·회복·주의 대상 — 독립 섹션, 첫 줄에 개인차 문구(본문 크기)**
   - 생활 관리
   - 진료가 필요한 신호 / 상담 때 물어볼 질문
7. **마무리** — 개인차·진료 후 결정. 예약 유도는 최소.
8. **참고 문헌** — 3~10건. 저자, 제목, 학술지, 연도, 링크(PubMed/DOI/기관). 기관·학회·질병관리청 자료 우선. 가능하면 연구 설계 표기(체계적 문헌고찰 등).
9. **하단 고지** — 일반 정보·진단 대체 불가·개인차.

## 3. 문장·근거 규칙

- 수치: 유병률, 부작용 빈도, 크기 같은 **비효능 수치만**, 바로 옆에 출처 번호. "○% 개선", 자체 시술 성과 금지.
- 인용: 학회 지침·논문·공공기관 문장만. 환자 말·후기 금지.
- 어조: 차분한 설명. "최고·유일·완치·확실" 금지. 단정 대신 "보고됐어요", "~일 수 있어요".
- 비교: 시술 **방식**끼리 특징 비교만. 병원·장비 우열 금지.
- 쉬운 말: 의학 용어는 처음 나올 때 괄호로 풀이.
- 출처가 없는 내용은 쓰지 않는다. 병원이 정할 사실(시행 시술, 횟수, 비용, 주의 대상)은 `[원장님 확인: …]`.
- 실명 비공개 병원은 실명·지점명을 쓰지 않는다("저희 병원"). 공개 병원도 제목에는 병원명을 넣지 않는다.
- 작성자·태그에 "○○피부과" 같은 진료과 명칭을 쓰지 않는다(제9호). 신고된 진료과목 확인 전까지 작성자는 "블로그 편집팀".
- 전문의약품 이름은 쓰지 않는다(약사법 대중광고 제한). "바르는 약, 먹는 약"으로 표현.

## 4. 이미지

- 생성 방법은 references/images.md. AI 이미지는 글자 없이, 라벨은 HTML로 얹기.
- 의학적 위치(깊이·부위)는 직접 그리거나 생성 후 문헌과 대조.
- 금지: 실제 인물 사진풍, 시술 장면, 전후 비교, 기기 상표.
- **사람 이미지**: 궁금해하거나 고민하는 사람을 **따뜻한 수채화 일러스트**로만 쓴다.
  - 이미지 바로 아래에 `*AI로 만든 일러스트이며 실제 환자가 아닙니다.*`를 붙인다(치료 사례·경험담 오인 방지, 제2·3호).
  - 고민하는 모습만. 좋아진 얼굴, 두 장 나란히 배치 등 전후 비교로 읽히는 구성 금지.
  - 울거나 절망하는 과장 금지. 차분하게 살펴보는 표정.
  - 글 주제와 맞는 장면만(예: 흉터 글에 매끈한 피부 모델 금지).
- alt는 20자 이상으로 그림 내용을 설명.

## 5. 네이버 형식

- 문단 2~3줄, 표 1~3개, 소제목마다 이미지 또는 표로 쉼표.
- 한 줄 쪼개기 문체 금지. 이모지 금지.
- 핵심 키워드: 제목 1회, 소제목 2~3곳. 반복 나열 금지.

## 7. 병원마다 정해야 하는 것 (사용자 결정, docs/decisions.md에 기록)

- 의학 감수 표기 방식: 직함만 / 실명·자격 / 표기 없음. 실명 비공개 방침과 감수자 표기(GEO·신뢰 핵심)의 균형. "전문의"는 실제 자격이 있을 때만.
- 진료과목 명칭: 전문의 개설 여부와 신고 진료과목에 따라 "○○피부과" 명칭 사용 가능 여부가 갈린다(제9호).
- 사전심의: 대상 매체·형식인지, 신청 시 광고 주체 표기와 실명 비공개의 충돌 여부(심의기관 확인).
- 글 끝 안내 범위: 주소·진료 시간·예약 방법을 어디까지 넣을지(실명 비공개라면 주소가 병원을 드러낸다).
- 네이버 공식 블로그 인증 신청 여부.
