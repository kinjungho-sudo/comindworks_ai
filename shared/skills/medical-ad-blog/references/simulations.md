# 시뮬레이션 검수 지침

자동 검사기를 통과한 원고에 대해 에이전트 2개를 **한 메시지에서 동시에** 띄운다. 두 에이전트에는 원고 경로와 아래 지침만 넘긴다. 내가 무엇을 걱정하는지, 무엇을 이미 고쳤는지는 넘기지 않는다. 넘기면 에이전트가 내 결론을 확인하는 데 그치기 때문이다.

결과를 받으면 다음 순서로 처리한다.
1. 지적마다 반영할지 정한다. 반영하지 않는 지적은 이유를 검수 기록에 남긴다.
2. 새 의학 사실을 넣어야 하면 출처를 먼저 찾는다. 출처가 없으면 빼거나 `[원장님 확인]`으로 남긴다.
3. 원고를 고친 뒤 `medad_check.py`와 `geo_check.py`를 다시 돌린다.
4. `docs/reviews/<날짜>_<슬러그>.md`에 남긴다.

---

## A. 독자 시뮬레이션

```
아래 원고는 병원 블로그 글이다. 이 글을 처음 읽는 예비 환자 4명이 되어 읽어 줘.
원고: <원고 경로>

네 사람은 나이, 고민, 읽는 방식, 들어온 경로가 서로 달라야 한다. 예:
- 처음 알아보는 20~30대, 휴대폰으로 훑어 읽음
- 이미 시술 경험이 있고 꼼꼼히 비교하는 40~50대
- 걱정이 많아 부작용 부분을 먼저 찾는 사람
- 검색 결과나 AI 답변에서 링크로 들어와 한 섹션만 읽는 사람
주제에 맞게 구체적인 인물을 정해.

사람마다 다음을 적어 줘.
1. 이 글을 읽으러 온 핵심 질문과, 그 답을 얻었는지 (얻었다면 어느 섹션에서)
2. 답을 못 얻은 질문
3. 뜻이 헷갈린 말과 그 이유 (전문 용어, 같은 말이 다른 뜻으로 쓰인 곳)
4. 읽다가 그만둘 것 같은 지점과 이유
5. 병원에 연락하기 전에 더 알고 싶은 것

마지막에 네 사람에게 공통으로 걸린 문제를 중요한 순서로 정리해 줘.
의학 사실을 새로 지어내서 제안하지 말고, "이 정보가 필요하다"는 형태로만 제안해.
```

## B. 심의 시뮬레이션

```
너는 의료광고심의위원회 심의위원이다. 아래 병원 블로그 원고를
의료법 제56조 제2항(1~15호)·시행령 제23조, 약사법의 전문의약품 광고 제한 기준으로 엄격하게 심의해 줘.
원고: <원고 경로>

1. 위험 문장: 줄 번호, 원문, 해당 호, 이유, 고친 문장 예시
   - 효과 보장, 과장, 최상급, 비교, 경험담 오인, 부작용 축소를 특히 본다.
   - 부정문이라도 결과적으로 안전이나 효과를 보장하게 읽히면 지적한다.
   - 작성자, 태그, 이미지 설명, 파일명도 본다 (제9호 명칭, 전후 비교).
2. 누락 정보: 시술을 다루는데 빠진 부작용, 주의 대상, 개인차 고지
3. 인용 대조 (가장 중요): 본문의 [번호] 인용마다 참고 문헌 원문(초록·본문)을 직접 열어 확인해.
   - 원문이 그 문장을 실제로 받치는지 판정: 일치 / 부분 일치 / 원문에 없음 / 확인 불가
   - 수치·범위·대상(연구 대상 집단)이 원문과 같은지
   - 서지 정보(저자, 제목, 학술지, 연도)가 맞는지
   - 제조사 후원·소규모 연구처럼 근거가 약한 출처
4. 판정: 통과 / 조건부 통과(조건 명시) / 보완 필요
   - [원장님 확인] 자리표시는 위반이 아니다. 발행 전 채워야 할 항목으로만 적어.

추측으로 원문 내용을 단정하지 말고, 열어 보지 못한 원문은 "확인 불가"로 적어.
```

---

## 통과 기준

- **독자**: 네 사람 모두 핵심 질문의 답을 얻어야 한다. 이탈 지점은 고치거나 이유를 남긴다.
- **심의**: "통과", 또는 "조건부 통과"(조건이 원장님 확인 항목뿐일 때)여야 한다. "보완 필요"면 반영 후 다시 검사한다. 고친 범위가 크면 심의 에이전트를 한 번 더 돌린다.
