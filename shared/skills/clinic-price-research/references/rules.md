# 조사 원칙과 이유

## 1. 강남언니 이용 방식

- `unni.app/robots.txt`(2026-11-19 확인)는 구글·네이버(Yeti)·다음 등 검색엔진만 허용하고 그 밖의 자동 수집(`User-agent: *`)은 `Disallow: /`다. 같은 파일 머리의 Content-Signal은 `search=yes, ai-input=yes, ai-train=no`로, AI가 사용자 질문에 답하려고 읽는 것(ai-input)은 허용, 학습은 금지로 표시한다.
- 그래서 이 도구는 **사람이 요청한 한 번의 조사**에 맞춰 설계했다.
  - 정기 자동 실행(cron, 스케줄 작업) 금지. 월 1~2회, 필요할 때 사람이 돌린다.
  - 한 번에 목록 최대 80장, 상세 최대 150장. 요청 간 4~7초 대기. 같은 날 같은 주소는 다시 열지 않는다.
  - 비로그인 공개 화면만. 로그인·후기 본문·사진·쿠폰·예약 기능은 쓰지 않는다.
  - 접속 주체를 숨기지 않는다(User-Agent에 도구 이름 표기). 차단(403·429)이나 보안 확인 화면이 나오면 즉시 멈춘다.
  - 수집한 원문 HTML은 그날 조사의 근거로만 보관하고(`raw/`, git 제외), 외부에 재배포하지 않는다.
- 강남언니 이용약관이 바뀌거나 운영사가 중단을 요청하면 그 즉시 사용을 멈춘다.

## 2. 의료광고 규정과의 관계

- 조사 결과는 **내부 의사결정용**이다. 블로그·광고·SNS·홈페이지에 다른 병원의 가격, 순위, 비교를 싣지 않는다 (의료법 제56조 제2항: 다른 의료기관과 비교·비방하는 광고 금지, 서면 피부과 BRAND.md Never do).
- 우리 병원 이벤트가를 광고할 때는 비급여 진료비용 할인·면제 광고 제한 등 별도 규정이 있다. 원고는 medical-ad-blog 검사기와 사전심의 대상 여부 확인을 거친다.

## 3. 숫자를 읽는 법

- 강남언니 가격은 **앱 결제 이벤트가**다(대개 VAT 포함). 정가·상담 후 실제 결제가와 다를 수 있다.
- "체험가", "첫방문", "1부위" 같은 미끼성 최저가가 섞인다. 최저가보다 **중앙값·용량별 가격·단위당 가격**을 본다.
- 같은 이름이라도 장비 세대(울쎄라 vs 울쎄라피 프라임, 써마지 FLX), 국산/수입(보톡스), 수면마취 포함 여부가 다르다. 가격 결정 전에는 원문 옵션을 확인한다.
